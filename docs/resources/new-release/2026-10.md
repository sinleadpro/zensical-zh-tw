    <h3 id="b1" style="font-size: 22px; font-weight: bold; color: #222222; margin: 0 0 16px 0; line-height: 1.3;">1. 黑貓訂單出貨文件支援直接列印</h3>

    <div style="color: #4B5563; font-size: 18px; line-height: 1.75; margin-bottom: 32px;">
      <p style="margin: 0 0 8px 0;">想更快速地列印託運單、訂單明細等文件，減少下載與開啟檔案的操作步驟？</p>
      <p style="margin: 0 0 8px 0;">使用 CYBERBIZ 串接的黑貓宅配或黑貓快速到店服務，出貨時可直接列印託運單、訂單明細、出貨明細與揀貨單。點選列印後，系統將於瀏覽器另開新分頁，顯示所勾選文件的 PDF，方便直接列印；若需留存檔案，也可同步下載。</p>
      <p style="margin: 0;">另支援依「文件類型」或「訂單編號」設定列印排序，方便依不同作業習慣安排列印順序。本次率先支援黑貓宅配與黑貓快速到店，後續也將陸續優化其他物流方式，提供更便利的出貨體驗！</p>
    </div>

    <h3 id="b2" style="font-size: 22px; font-weight: bold; color: #222222; margin: 0 0 16px 0; line-height: 1.3;">2. 前台站內搜尋（放大鏡）功能優化</h3>

    <div style="color: #4B5563; font-size: 18px; line-height: 1.75; margin-bottom: 32px;">
      <p style="margin: 0 0 8px 0;">消費者不一定記得完整商品名稱，希望輸入部分關鍵字，也能更容易找到想要的商品？</p>
      <p style="margin: 0 0 8px 0;">本次優化前台商品搜尋功能，支援中文關鍵字斷詞比對與型號前綴搜尋，並調整預設排序方式，依搜尋相關性排列結果，讓搜尋結果更貼近消費者的需求。</p>
      <p style="margin: 0 0 8px 0;">範例：</p>
      <p style="margin: 0 0 4px 0;">• 中文關鍵字：搜尋「台灣烤玉米」，即可找到「【台灣】黑豆烤玉米」</p>
      <p style="margin: 0 0 4px 0;">• 商品型號：搜尋「CH」或「CH2026」，即可找到型號為「CH2026GW16T-3」的商品</p>
      <p style="margin: 0;">• 搜尋排序：商品 A 的「商品名稱」含搜尋關鍵字、商品 B 僅在「商品介紹」中含有時，商品 A 會排在前面</p>
    </div>
