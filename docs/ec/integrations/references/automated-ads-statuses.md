 自動化廣告投放與開通狀態對照表

## 開通狀態對照表 { #automated-ads-apply-status }

| 狀態 | 說明 |
| :-- | :-- |
| 申請開通中 | 已完成首次儲值，CYBERBIZ 正在為您建立帳戶並進行 GMC 串接，約需 3~5 個工作天 |
| 開通完成 | 帳戶與 GMC 串接完成，可開始設定並投放廣告 |

!!! note "註釋"
    * 開通進度會以 email 通知，亦可於頁面上方的開通提示查看。
    * 使用「商家自有帳號」時，系統每日檢查 Google Ads 綁定狀態，綁定完成後才會開通。

## 廣告投放狀態對照表 { #automated-ads-delivery-status }

| 投放狀態 | 說明 |
| :-- | :-- |
| 投放中 | 廣告正常曝光，於「活動管理」可查看即時花費 |
| 暫停中 | 廣告已暫停曝光，常見於商家主動暫停，或廣告費餘額不足而自動暫停 |

!!! note "註釋"
    * 廣告費餘額不足時，系統會自動暫停投放，儲值後即可恢復。
    * 可於「Google 廣告設定」手動點擊「暫停投放」或「恢復投放」切換狀態。
