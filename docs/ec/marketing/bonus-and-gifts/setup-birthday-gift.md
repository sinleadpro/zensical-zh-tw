# 設定生日禮
設定會員生日禮，包含紅利點數與優惠券的發送規則、自動排程邏輯及提前發送設定。
{ .subtitle }

[:lucide-tag:{ title="適用方案" }](../../../resources/conventions#適用方案) | 所有 PLUS / 企業
{ .doc-badge }

![](https://www.cyberbiz.io/support/wp-content/uploads/行銷活動-生日禮01.png){ .hero-page }

!!! tip "應用情境"
	- **會員維繫**：生日當月自動送禮，增加品牌好感度並吸引回購。
	- **自動化營運**：設定一次後系統自動排程發送，節省人力成本。
	- **分級獎勵**：結合 VIP 制度，給予高價值會員更優渥的生日禮遇。


## 生日禮規則

### 發送排程

- **發送時間**：系統預設當月 1 號發送該月生日禮。
- **提前發送**：生日禮若需提前發送，必須在發送日前 **2 日** 完成設定，系統才能正確排查名單。
  
    例：7 月生日禮若想提前 5 天發送，最晚請於 6/24 設定「提前 5 天發送生日禮」，系統才可於 6/26 發送 7 月生日禮。

- **排查時間**：當日凌晨 3 點，系統開始檢查符合條件的會員，並依序發送。

    > 會員收到生日禮的確切時間，可能依系統作業時間而有些許差異。

- **發送通知時間**：若已於 **訊息推播 > Email通知樣板** 或 **簡訊通知樣板** 啟用生日禮通知。系統會於當日中午 12 點，統一寄送通知給會員。

### 會員領取規則

- **生日當月註冊**：新會員若在生日當月註冊，完成後系統將立即發送生日禮，不受 **提前 N 天發送生日禮** 設定限制。
- **單次領取原則**：生日禮發送週期內（自提前發放日起至生日月底），每位會員限領取 **一次一般會員生日禮**。

### 相關操作

- **疊加贈送**：若您在 **會員 > VIP 設定** 中另外設定了 [VIP 生日禮](../../members/vip/setup-exclusive-vip-discounts.md#4-生日禮設定)，系統將會同時發送一般生日禮與 VIP 生日禮。
- **刪除生日禮**：請至 **會員 > 所有會員**，點選個人頁面，[手動收回](../../members/manage-member-profiles.md#任務四資產配置) 優惠券或紅利點數。
- **批次匯入會員**：匯入時可透過 **贈送生日禮** 欄位決定是否發送當月生日禮給該批新會員。

    | 欄位值 | 系統行為 |
    | ------ | ------- |
    | 是 | 若後台開啟生日禮功能，則匯入當月生日禮會發送 |
    | 否 | 匯入當月生日禮不發送，其他月份依後台設定發送 |

## 操作流程

### 1. 設定生日禮內容

1. 登入 CYBERBIZ 管理後台，前往 **行銷活動 > 全館折扣 – 紅利&優惠券 > 會員生日贈送優惠券/紅利點數**。
2. 將功能切換為 `開啟`。
3. 設定發送規則：
    - **生日禮標題**：預設為 `年月+生日禮`（請保留 `{{date}}` 變數以自動帶入日期）。
    - **每月提前贈送**：設定是否要在生日當月 1 號之前提前發送（如提前 5 天）。
4. 設定贈送內容：
    - **紅利點數**：輸入贈送點數（0 代表不贈送）。

        - **生效起始**：紅利點數將於發送後立即生效，有效期限至生日當月月底。

    - **優惠券**：設定種類（金額/百分比）、折價數值、使用次數、滿額門檻及併用限制。

        - **生效起始**：優惠券限定生日當月使用。


## 常見問題

??? quote "可以修改生日禮的通知內容嗎？"
    可以。請前往 **訊息推播 > Email通知樣板** 或 **簡訊通知樣板**，在「顧客相關」分類中找到「顧客獲得生日個人優惠券通知」進行編輯。

??? quote "我在 7/20 設定提前 15 天發送生日禮，為什麼 8 月壽星沒收到？"
    因為 7/20 距離 8/1 僅剩 12 天，已超過您設定的「提前 15 天」門檻。系統在 7/17（8/1 的前 15 天）就已完成 8 月壽星的排查。請將天數調低（如 10 天）即可於隔日發送。

??? quote "如果我調整了提前發送天數，已經領過的人會再領一次嗎？"
    會。系統是根據「是否符合下個月生日條件」來發送。若您在發送後縮短提前天數，導致系統再次觸發發送邏輯，符合條件的會員將會重複領取。
