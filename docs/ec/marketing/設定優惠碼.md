# 設定優惠碼
設定優惠碼（折扣、免運、贈品），包含基本設定、使用門檻、發送規則及結帳頁自動套用功能。
{ .subtitle }


![](https://www.cyberbiz.io/support/wp-content/uploads/行銷活動-優惠碼01.png){ .hero-page }

!!! tip "應用情境"
	- **異業合作**：提供專屬優惠碼給合作夥伴，追蹤不同管道的轉單成效。
	- **節慶促銷**：建立限時限量的折扣碼，營造搶購氛圍。
	- **滿額贈禮**：發送贈品券，讓消費者在達成門檻後能自選心儀贈品。
	- **降低棄單**：開啟自動套用優惠碼功能，讓消費者在結帳時直接感受優惠。


## 使用須知

- **不歸戶特性**：優惠碼屬於「不歸戶」形式，任何會員只要獲得序號即可在結帳頁套用。
- **大小寫不限**：優惠碼不區分字母大小寫，方便消費者輸入。
- **運算順序**：優惠碼與優惠券屬於同一階層，系統會優先套用序號相同的個人優惠券。

### 免運券規格

- **編輯限制**：免運券設定完成後即無法編輯。若需更新內容，必須刪除並重新新增。
- **紅利商城適用性**：紅利商城若使用免運券，將不受該券的「消費使用門檻」限制，皆可直接折抵運費。

### 贈品券規格

- **商品限制**：贈品券不支援組合品。
- **通路限制**：贈品券不支援 POS、定期定額及 CYBERBIZ NOW! 快速到貨。
- **串倉物流限制**：串倉商家使用贈品券時，贈送商品必須填寫 SKU 碼，否則會套用失敗。
- **API 串接**：
    - API / webhook 的訂單商品裡會出現。
    - 支援透過 API 方式，新增贈品券。
- **空購物車判定**：系統不支援「購物車內僅有贈品券商品」的情境。若購物車中未包含任何一般付費商品，系統將判定該購物車為「空購物車」，進而無法執行後續結帳流程。
- **上架限制**：贈品券僅支援與「已上架」的一般商品進行綁定。
- **下架觸發**：若綁定的主商品變更為「下架」狀態，該贈品券將自動失效並同步下架，使用者無法於前台購物車中搜尋、檢視或折抵該贈品券。



## 操作流程

### 1. 新增優惠碼

1. 登入 CYBERBIZ 管理後台，前往 **行銷活動 > 優惠碼**。
2. 點擊 **新增優惠碼**。
3. **基本設定**：
    - **優惠碼名稱**：輸入名稱（會員前台可見）。
    - **活動時間**：設定不限期或指定活動期間。

=== "折價"

    提供固定金額或百分比折扣。

    - **折扣內容**：選擇「金額」或「百分比」（如 9 折輸入 90%）。
    - **兌換序號**：自訂序號或選擇由系統自動產生。
    - **最高折抵金額**：若選擇百分比，可設定單筆最高折抵上限。(企業版專用)
    - **消費使用門檻**：設定單筆消費需滿多少元才可使用。
    - **全站使用上限**：此優惠碼在全站可被折抵的總次數上限。
    - **帳號使用次數**：單一會員帳號重複使用此優惠碼的次數上限。(PLUS、企業版專用)
    - **綁定商品標籤**：可指定此優惠券僅適用於帶有特定標籤的商品。(進階、高手、PLUS、企業版專用)
    - **與其他活動的併用限制**：選擇此優惠券與其他行銷活動的堆疊規則，包含：`無限制`、`部分限制` 或 `不可與優惠活動併用`。

    ![](https://www.cyberbiz.io/support/wp-content/uploads/行銷活動-優惠碼03.png){ .screenshot }

=== "免運"

    !!! note "方案限制"
        此功能僅支援 **PLUS版、企業版**。

    提供免運費優惠，降低購物負擔。

    - **兌換序號**：自訂序號或選擇由系統自動產生。
    - **消費使用門檻**：設定單筆消費需滿多少元才可使用。
    - **全站使用上限**：此優惠碼在全站可被折抵的總次數上限。
    - **帳號使用次數**：單一會員帳號重複使用此優惠碼的次數上限。
    - **商品限制**：可設定僅購買指定商品或標籤時才可免運。
    - **綁定物流**：可限制僅特定物流方式（如 7-11 取貨）才適用此優惠。

    ![](https://www.cyberbiz.io/support/wp-content/uploads/行銷活動-優惠碼04.png){ .screenshot }

=== "贈品"

    !!! note "方案限制"
        此功能僅支援 **企業版**。

    達成門檻後贈送特定商品。

    - **兌換序號**：自訂序號或選擇由系統自動產生。
    - **消費使用門檻**：設定單筆消費需滿多少元才可使用。
    - **全站使用上限**：此優惠碼在全站可被折抵的總次數上限。
    - **帳號使用次數**：單一會員帳號重複使用此優惠碼的次數上限。
    - **兌換品項**：選擇欲贈送的商品（僅能依商品設定，無法指定款式）。
      
        > **庫存邏輯**：系統將依款式順序發送，直到所有款式庫存耗盡。


    ![](https://www.cyberbiz.io/support/wp-content/uploads/行銷活動-優惠碼05.png){ .screenshot }




### 2. 批次建立優惠碼

若需一次建立多筆全館型優惠碼（**僅限折價或免運**），可使用批量匯入功能。

!!! note "方案限制"
    此功能僅支援 **企業版**。

1. 在 **行銷活動 > 優惠碼** 頁面，點選 **批量匯入優惠碼**。
2. 下載系統提供的 CSV 範本檔案。
3. 依照範本格式填寫優惠碼資訊（如名稱、序號、門檻、效期等）。
4. 上傳檔案並選擇欲匯入的類型（折價或免運），系統即會完成建立。

    ![](https://www.cyberbiz.io/support/wp-content/uploads/行銷活動-優惠碼17.png){ .screenshot }

### 3. 開啟結帳頁優惠券（碼）欄位

若要讓顧客在結帳時能使用優惠券（碼），必須先開啟前台顯示開關。

1. 登入 CYBERBIZ 管理後台，前往 **金物流 > 結帳頁 & 物流設定**。
2. 找到 **結帳頁優惠券設定** 區塊，將功能切換為 `開啟`。

    ![](https://www.cyberbiz.io/support/wp-content/uploads/行銷活動-優惠碼13.png){ .screenshot }



### 4. 設定結帳頁自動套用優惠碼

此功能可自動為符合條件的訂單套用優惠碼，不需消費者手動輸入。


!!! note "方案限制"
    自動套用功能僅限 **高手 PLUS 版** 與 **企業版** 使用。


=== "高手 PLUS 版"

    - **單組綁定**：僅支援綁定 **1 組** 優惠碼。
    - **觸發邏輯**：若購物車中已存在優惠碼，則 **不會** 觸發自動套用。

=== "企業版"

    - **多組綁定**：至多可設定 **5 組** 優惠碼，並可拖曳排序套用順序。
    - **觸發邏輯**：若購物車中已存在優惠碼，系統亦會觸發自動套用機制。
    - **張數限制**：可自動套用的數量受限於「每筆訂單可使用優惠券張數」設定。

#### 使用須知

- 此功能僅供官網結帳頁使用，**不適用一頁式商店**。
- 支援折價券、免運券、贈品券。
- 網站會員註冊方式為「快速結帳並註冊」與「必須註冊」，皆可適用。

#### 設定步驟

1. 前往 **金物流 > 結帳頁 & 物流設定 > 結帳頁優惠券設定**。
2. 開啟 **自動套用優惠碼** 開關。
3. 輸入欲自動套用的 **全館型優惠碼序號**。
4. 設定完成後，當消費者進入結帳頁且符合門檻時，系統將自動套用該優惠。

    ![](https://www.cyberbiz.io/support/wp-content/uploads/行銷活動-優惠碼16.png){ .screenshot }

#### 適用優惠碼類型

| 類型 | 說明 | 是否適用自動套用 |
| :--- | :--- | :--- |
| **全館型優惠碼** | 於 **行銷活動 > 優惠碼** 新增，視為全館型優惠碼 | 適用 |
| **會員專屬優惠碼** | 於 **會員 > 所有會員** 勾選指定會員並發送 | 不適用 |
| **優惠券** | 於 **行銷活動 > 全館折扣-紅利&優惠券** 新增 | 不適用 |





## 結帳流程

消費者在結帳頁點擊「選擇優惠券或輸入優惠碼」。

![](https://www.cyberbiz.io/support/wp-content/uploads/優惠券-多張優惠券設定03.png){ .screenshot }

若「全館優惠碼」與「個人優惠券」序號相同，系統優先套用 **個人優惠券**。

![](https://www.cyberbiz.io/support/wp-content/uploads/行銷活動-優惠碼08.png){ .screenshot }

=== "免運"

    1. 未使用免運券前，系統顯示原始運費。
    2. 選擇或輸入免運券代碼。
    3. 套用後，運費欄位將更新為 **（優惠券免運）**。

    ![](https://www.cyberbiz.io/support/wp-content/uploads/免運券05.png){ .screenshot }

=== "贈品"

    若贈品庫存足夠，消費者可選擇套用該贈品券。

    ![](https://www.cyberbiz.io/support/wp-content/uploads/行銷活動-優惠碼09.png){ .screenshot }




## 贈品券使用規則

### 庫存檢查順序

當訂單成立時，系統會依以下順序檢查庫存，若贈品券商品庫存不足，系統將提示消費者刪除該券後再結帳：

1. 組合品
2. 一般商品
3. 首購禮商品
4. 滿額/件贈商品
5. **贈品券商品**

### 數據分析

贈品券屬於優惠券的一種，其成效可於後台 **圖表分析 > 行銷活動分析 > 優惠券分析** 中查看。若是由會員列表發送的贈品券，系統將視為「會員專屬優惠券」。

### 特殊情境處理

1. **套用失效**：若在套用贈品券後發生「重整購物車」、「更新購物車商品」或「贈品庫存不足」等情況，可能導致贈品券無法套用或顯示錯誤。此時消費者需刪除該券後重新結帳。
2. **最低消費限制**：即使贈品券門檻設為 0 元，購物車內仍須包含至少一個一般商品（非贈品）。若購物車為空，消費者將被導回首頁或會員頁面。
3. **門檻與庫存判定順序**：若同時觸發「未達消費門檻」與「贈品庫存不足」，系統會優先判斷消費門檻。



## 常見問題

??? quote "優惠碼可以限制只能給新會員使用嗎？"
    優惠碼本身不歸戶，無法直接限制新舊會員。若需針對特定對象，建議使用「個人優惠券」發送至指定會員帳戶。

??? quote "為什麼我的贈品券無法套用？"
    請檢查以下幾點：
    1. 贈品商品是否有庫存。
    2. 贈品商品是否已填寫 SKU（針對串倉商家）。
    3. 購物車內是否已有其他商品（購物車不能僅有贈品）。


??? quote "如何發送贈品券？"
    您可以透過以下兩種主要方式發送贈品券：
    1. **[會員列表手動發送]()**：在會員 > 所有會員」中勾選指定對象，點選「發送贈品券」。
    2. **[互動遊戲獎勵]()**：在「行銷活動 > 互動遊戲」中，將贈品券設定為中獎獎勵，讓消費者參與活動後自動獲得。
