## 規格與限制 { #tcat-specs }

- **重量限制**：單件包裹重量需在 **20kg** 以內。
- **尺寸計算**：尺寸為包裹之長+寬+高之總和。
- **單邊限制**：黑貓宅急便目前無單邊長限制，僅依總計尺寸判定。
- **貼紙規定**：列印託運單請務必使用 **「黑貓三聯空白託運單貼紙」** (A4 三模)。如未持有，請先致電黑貓客服 (02-412-8888) 索取。

## 額外費用說明 { #tcat-extra-fees }

| 情境 | 加收金額 | 說明 |
| :-- | :-- | :-- |
| **溫層混配處理費** | 每張 +50 Cyber 幣 | 列印常溫託運單卻以低溫寄送，或反之，作為帳務處理費。 |
| **物流繁盛期** | 每張 +10 Cyber 幣 | 於三大節日（端午、中秋、春節）前一週，黑貓收取繁盛期服務費。 |
| **運費差額補收** | 視實際狀況 | 若實際包裹尺寸/溫層大於系統設定，將於對帳單補收差額。 |
| **離島加價** | 依黑貓公告 | 配送至離島地區（澎湖、金門、馬祖、綠島）依黑貓官方費率計價。 |

!!! note "註釋"
    * 金額均為 **Cyber 幣** (1 點 = 1 NTD)，且 **含稅**。
    * 若您與 CYBERBIZ 已協議 **客製費率**，系統會自動套用，實際扣抵以後台下拉選單為準。
    * **促銷期間** 部分尺寸會有優惠價，系統會自動以優惠價扣抵。

[^busy]: 於端午、中秋、春節期間加收。
[^mismatch]: 列印託運單時若實際寄送溫層與標示不符時加收。
