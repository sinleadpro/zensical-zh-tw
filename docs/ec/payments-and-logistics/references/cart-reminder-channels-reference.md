# 購物車未結帳提醒管道對照表

本對照表彙整「顧客購物車未結帳商品自動提醒」可使用的通知管道與開通條件,供結帳頁與金物流相關設定引用。

## 提醒管道與開通條件 { #cart-reminder-channels }

| 提醒管道 | 說明 | 開通條件 |
| :-- | :-- | :-- |
| Email 提醒 | 以電子郵件提醒顧客購物車仍有未結帳商品 | 多數付費方案內建 |
| 簡訊提醒 | 以簡訊提醒顧客,發送時依內容長度消耗 Cyber幣 | 多數付費方案內建 |
| LINE OA 提醒 | 透過 LINE 官方帳號推播提醒 | PLUS版以上或企業版 |

!!! note "註釋"
    * 提醒最多可設定三次,各次的發送天數上限為 14 天。
    * 簡訊與 LINE OA 提醒會消耗 Cyber幣,若餘額不足將發送失敗,請先確認餘額。
    * 各管道的通知內容可至對應的「Email & 提醒」「簡訊設定」「LINE@設定」頁面調整。
    * 是否顯示某個管道,依您店家實際開通的功能動態變化。
