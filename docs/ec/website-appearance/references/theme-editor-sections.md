# 可新增區塊類型對照表

本對照表彙整拖拉版型中可新增的區塊及其用途,供「拖拉版型網站設定」等說明引用。

## 常見可新增區塊 { #theme-editor-sections }

| 區塊類型 | 適用頁面 | 說明 | 開通條件 |
| :-- | :-- | :-- | :-- |
| 輪播素材 | 首頁、自訂頁面 | 多張圖片輪播,常用於頁面主視覺與活動曝光 | — |
| 橫幅廣告 | 首頁、自訂頁面 | 單張大型橫幅,可加上按鈕導購 | — |
| 商品分類 | 首頁、自訂頁面 | 商品櫥窗,展示某一分類的商品群 | — |
| 影片設定 | 首頁、自訂頁面、單頁式頁面 | 嵌入 YouTube 影片 | — |
| 分頁頁籤 | 首頁 | 以頁籤切換展示多個部落格群組 | — |
| 自訂排版設計 | 首頁、自訂頁面、單頁式頁面 | 同一橫列混排多種元件(圖片/影片/排程跑馬燈/自訂 HTML/商品) | — |
| 圖文介紹 | 首頁、自訂頁面、單頁式頁面 | 圖文並排,適合品牌或主打說明 | — |
| 自訂 HTML | 首頁、自訂頁面、單頁式頁面 | 貼入自訂 HTML / CSS,或嵌入第三方服務(如 IG 動態牆) | — |
| 應用程式 | 首頁 | 顯示已安裝應用程式提供的內容 | — |
| 文字編輯 | 首頁、自訂頁面、單頁式頁面 | 純文字內文,可調整字級 | — |
| 主打商品 | 首頁 | 強調單一重點商品 | — |
| 折疊內容 | 首頁、自訂頁面、單頁式頁面 | 可點擊展開/收合的內容,適合 FAQ、購物須知 | — |

!!! note "註釋"
    * 上表為常見的可新增區塊,**實際可新增的區塊與其名稱會依您安裝的拖拉版型與方案而不同**,請以編輯器內「新增區塊」清單顯示的為準。
    * 各區塊的詳細欄位(圖片尺寸、輪播秒數、商品欄數、邊距等)請見 [各頁面設定](../theme-editor-page-settings.md){ title="各頁面設定" }。
    * **商品頁面為固定區塊**(商品資訊、商品介紹、相關商品、商品評論,其中商品評論需開通加值功能),不會出現在「新增區塊」清單中,設定方式見 [各頁面設定](../theme-editor-page-settings.md#product){ title="各頁面設定" }。
    * **彈窗廣告、頁首選單、頁尾屬於全站共用設定**,不是可新增區塊;彈窗廣告的設定見 [全站共用設定](../theme-editor-global-settings.md#popup){ title="全站共用設定" }。
    * 部分區塊底下還包含多個小區塊(如輪播素材的每一張圖片、自訂排版設計的每個元件),可點入後逐一設定。
