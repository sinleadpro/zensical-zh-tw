### 頁腳聯絡資訊欄位 { #footer-contact-fields }

| 欄位 | 說明 |
| :-- | :-- |
| 標題 | 聯絡資訊區塊在前台顯示的標題文字，預設為「聯絡資訊」 |
| 顯示聯絡電話 / 聯絡電話 | 顯示開關搭配電話內容，供消費者聯繫客服 |
| 顯示傳真號碼 / 傳真號碼 | 顯示開關搭配傳真號碼內容 |
| 顯示營業時間 / 營業時間 | 顯示開關搭配營業(客服)時間說明 |
| 顯示信箱 / 信箱 | 顯示開關搭配客服 Email |
| 顯示聯絡地址 / 地址 | 顯示開關搭配公司或門市地址 |
| 顯示統一編號 / 統一編號 | 顯示開關搭配統一編號，供揭露營業人統編使用 |

!!! note "註釋"
    * 每個資訊欄位都需先勾選對應的「顯示」開關，前台頁腳才會呈現該項內容。
    * 此處的「統一編號」為前台揭露用的獨立欄位，與後台「一般設定」的統一編號各自獨立，需分別填寫。
