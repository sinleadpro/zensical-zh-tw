# 主題類型對照表 { #theme-types }

| 類型 | 說明 | 適合對象 |
| :-- | :-- | :-- |
| 拖拉版型 | 無需撰寫程式碼，以滑鼠點選與拖曳調整各區塊位置與版面，並支援最新前台功能。主題卡片標有「拖拉設定」標籤。 | 想自由調整版面、不寫程式的商家 |
| 預設版型 | 開放 HTML、CSS、JS 語法做深度視覺客製。系統已不再更新此類版型。 | 具技術背景、需要高度自訂的商家 |
| 多國版型 | 支援多國語言前台切換的版型，主題卡片標有「多國版型」標籤。 | 經營多國語言官網(如北美站、日本站)的商家 |

!!! note "註釋"
    * 主題庫預設顯示「新功能拖拉版型」分類；切換到「預設版型」分類時會提醒此類版型已停止更新。
    * 多國語言商店的主題庫內容會依商店所在地區自動調整，僅顯示適用的版型。
