本對照表彙整拖拉版型中，各頁面的編輯能力，供「拖拉版型網站設定」等說明引用。

## 各頁面編輯能力 { #theme-editor-pages }

拖拉版型的頁面依「能編到什麼程度」分為三種： **可自由增減區塊**、 **僅可排序/編輯既有區塊**、 **版面固定**。各頁面實際的設定欄位，請對照 [可新增區塊類型](theme-editor-sections.md)。

| 頁面 | 編輯能力 | 內含 / 可用區塊 |
| :-- | :-- | :-- |
| 首頁 | 自由新增、排序、刪除區塊 | 見 [可新增區塊類型](theme-editor-sections.md) |
| 自訂頁面 | 自由新增、排序、刪除區塊 | 見 [可新增區塊類型](theme-editor-sections.md) |
| 單頁式頁面 | 自由新增、排序、刪除區塊 | 見 [可新增區塊類型](theme-editor-sections.md) |
| 商品頁面 | 可排序、編輯既有區塊(不可新增) | 商品資訊、商品介紹、推薦商品、商品評論 |
| 商品群組頁面 | 版面固定，套用整體風格 | — |
| 商品多層級分類 | 版面固定，套用整體風格 | — |
| 部落格頁 | 版面固定，套用整體風格 | — |
| 部落格文章頁 | 版面固定，套用整體風格 | — |
| 購物車頁 | 版面固定，套用整體風格 | — |
| 快速到貨頁 | 版面固定，套用整體風格 | — |
| 客服頁 | 版面固定，套用整體風格 | — |
| 搜尋頁 | 版面固定，套用整體風格 | — |
| 404 頁 | 版面固定，套用整體風格 | — |

!!! note "註釋"
    * **自由新增、排序、刪除區塊**：可在「新增區塊」清單中加入區塊、拖曳調整順序、移除區塊。
    * **僅可排序/編輯既有區塊**：不能新增新區塊，但可調整既有區塊的內容與順序(例如商品頁的商品資訊、商品介紹、推薦商品、商品評論)。
    * **版面固定**：版面結構由系統決定，無法逐塊調整，但仍會套用版型的整體風格(顏色、字體等)。
    * 實際可編輯的頁面會依您安裝的拖拉版型而略有差異，請以編輯器上方的頁面下拉選單為準。
