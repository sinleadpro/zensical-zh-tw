# 可拖拉編輯的頁面對照表

本對照表彙整拖拉版型中,哪些頁面支援拖拉編輯,供「拖拉版型網站設定」等說明引用。

## 各頁面拖拉支援情形 { #theme-editor-pages }

| 頁面 | 支援拖拉編輯 | 說明 |
| :-- | :-- | :-- |
| 首頁 | 支援 | 商店的主入口頁面,可新增的區塊最多 |
| 商品頁面 | 支援 | 單一商品的呈現頁面,可調整商品資訊、介紹、推薦商品等區塊 |
| 自訂頁面 | 支援 | 您自行建立的頁面(如品牌故事、活動說明) |
| 單頁式頁面 | 支援 | 適合活動或一頁式商品的版面 |
| 商品群組頁面 | 不支援 | 商品分類列表頁,版面由系統固定 |
| 商品多層級分類 | 不支援 | 多層級分類瀏覽頁,版面由系統固定 |
| 部落格頁 | 不支援 | 文章列表頁,版面由系統固定 |
| 部落格文章頁 | 不支援 | 單篇文章頁,版面由系統固定 |
| 客服頁 | 不支援 | 聯絡與客服資訊頁 |
| 搜尋頁 | 不支援 | 站內搜尋結果頁 |
| 404頁 | 不支援 | 找不到頁面時的提示頁 |

!!! note "註釋"
    * 「支援拖拉編輯」指的是該頁面在拖拉版型編輯器中可以新增區塊、拖曳排序。
    * 不支援拖拉的頁面仍會套用版型的整體風格(顏色、字體等),只是版面結構由系統固定,無法逐塊調整。
    * 實際可編輯的頁面會依您安裝的拖拉版型而略有差異,請以編輯器上方的頁面下拉選單為準。
