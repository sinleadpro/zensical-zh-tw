## 自訂頁面可用區塊對照表 { #reference-custom-pages-blocks }

下列區塊適用於 **新版(拖拉式)自訂頁面**，於佈景主題編輯器中點擊 **「新增區塊」** 加入。各區塊可重複新增、自由調整順序。

| 區塊名稱 | 說明 | 使用條件 |
| :-- | :-- | :-- |
| 輪播素材 | 可自動輪播的多張圖片橫幅，常用於頁面主視覺與活動曝光，可設定每輪顯示張數。 | 內建 |
| 橫幅廣告 | 單張或多張橫幅圖片版位，每張可連結到指定網址，適合活動或主打商品導購。 | 內建 |
| 商品分類 | 以圖文區塊陳列商品分類入口，引導顧客點入對應分類頁瀏覽商品。 | 內建 |
| 自訂排版設計 | 自由調整多張素材的螢幕占比與排列順序，打造客製化的圖文版面。 | 內建 |
| 影片設定 | 嵌入影片並可設定自動播放等行為(自動播放時會自動轉為靜音)。 | 內建 |
| 圖文介紹 | 圖片搭配文字的介紹區塊，適合品牌故事、服務特色等說明內容。 | 內建 |
| 自訂 HTML | 自行貼入 HTML 語法或外部嵌入碼，例如 Google 表單、互動內容、第三方程式碼。 | 內建 |
| 文字編輯 | 以文字編輯器撰寫段落內容，適合服務條款、隱私政策、說明文章等大段文字。 | 內建 |
| 折疊內容 | 點擊後才展開的折疊式內容，常用於設計 FAQ、購物須知、常見問答。 | 內建 |

!!! note "註釋"
    * 區塊清單會依店家實際啟用的功能動態顯示，實際可用項目以佈景主題編輯器中的「新增區塊」面板為準。
