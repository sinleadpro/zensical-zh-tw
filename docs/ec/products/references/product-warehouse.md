「出貨方式」決定一支商品由誰負責倉儲與出貨。預設所有商品都是 **自行出貨**，若您有啟用第三方倉儲或跨境物流功能，才會出現對應的物流倉選項。

### 出貨方式對照表 { #reference-product-warehouse }

| 出貨方式 | 說明 | 適用條件 |
| :-- | :-- | :-- |
| 自行出貨 | 商品由您自行包裝出貨，庫存與出貨皆在後台手動管理。 |  |
| 倉儲 / 跨境物流倉 | 由第三方倉庫或跨境物流代為倉儲與出貨，訂單成立後依設定自動拋單。 | 需啟用對應的物流倉功能 |

!!! note "註釋"
    * 「出貨方式」下拉的可選倉庫 **依您已開通的物流功能動態顯示**，不同商店看到的選項不同。
    * 透過第三方倉庫出貨的商品，商品 **SKU 須與該倉庫內的 SKU 一致** 才能順利拋單。
    * 若無任何倉儲功能，商品一律為「自行出貨」。
