本對照表彙整 CYBERBIZ 前台多國語系功能目前支援的語言，供商品條件分類、商品、頁面等內容翻譯時共用參考。
## 支援語言對照表 { #multi-language-supported }

| 語言 | 顯示名稱 |
| :-- | :-- |
| 繁體中文 | 繁體中文 |
| 簡體中文 | 简体中文 |
| 英文 | English |
| 日文 | 日本語 |
| 泰文 | ภาษาไทย |
| 法文 | Français |
| 德文 | Deutsch |
| 西班牙文 | Español |
| 越南文 | Tiếng Việt |
| 韓文 | 한국어 |
| 印尼文 | Bahasa Indonesia |

!!! note "註釋"
    * 實際可在語言選單中切換的語言，取決於您商店已開通並啟用的語言；上表為系統支援的完整語言清單。
    * 繁體中文為系統預設語言，其餘語言需開通多國語系商店功能後才會啟用。
    * 各語言在前台選單的顯示名稱，會以該語言的當地寫法呈現(如日文顯示為「日本語」)。
