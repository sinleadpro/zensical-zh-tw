本對照表彙整「商品條件分類」可選擇的商品排序方式，決定符合條件的商品在前台分類頁的呈現順序。

## 商品排序方式對照表 { #smart-collections-sort-orders }

| 排序方式 | 商品在前台的排列順序 |
| :-- | :-- |
| 按標題拼音升序：A-Z | 依商品名稱由 A 到 Z(由小到大)排列 |
| 按標題拼音降序：Z-A | 依商品名稱由 Z 到 A(由大到小)排列 |
| 按創建日期：最近-最遠 | 最新建立的商品排在最前面 |
| 按創建日期：最遠-最近 | 最早建立的商品排在最前面 |
| 按價格排序：最高-最低 | 售價由高到低排列 |
| 按價格排序：最低-最高 | 售價由低到高排列 |
| 暢銷商品排序 | 依銷售表現由熱銷到冷門排列 |
| 手動排序 | 由您自行拖曳調整商品先後順序 |

!!! note "註釋"
    * 選擇「手動排序」後，符合的商品列表才能以拖曳方式調整順序；其餘排序方式由系統自動排列，無法手動拖曳。
    * 排序只影響商品在前台分類頁的呈現順序，不影響商品是否被納入分類(納入與否由篩選條件決定)。
