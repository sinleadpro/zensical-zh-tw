本對照表彙整商品在多國語系商店中，**可以逐語言分別填寫** 的欄位，供新增商品、多語系建置等說明引用。未列於下表的欄位(如價格、款式、SKU、庫存、圖片)為所有語言共用，只需設定一次。

## 可翻譯欄位 { #reference-product-multilang-fields }

| 頁籤 | 可翻譯欄位 | 說明 |
| :-- | :-- | :-- |
| 商品資訊 | 商品名稱 | 商品在前台顯示的主要名稱 |
| 商品資訊 | 商品標語 | 商品名稱附近的特色 / 促銷短句 |
| 商品資訊 | 商品簡述 | 商品的簡短描述 |
| 商品資訊 | 商品規格 | 規格的名稱(如「顏色」「尺寸」) |
| 商品資訊 | 規格項目 | 規格底下的項目(如「紅」「藍」) |
| 商品描述 | 商品描述 | 商品的主要介紹內容 |
| 商品描述 | 規格描述 | 規格、材質、尺寸等說明 |
| 商品描述 | 運送方式 | 出貨與配送相關說明 |

!!! note "註釋"
    * 切換語言後，上述欄位旁會顯示目前編輯的語言標籤，提醒您正在編輯哪一個語言的內容。
    * 切換語言前請先儲存，否則系統會跳出「編輯多國語言前，請先儲存變更中的內容」的提示。
    * 部分語言為 AI 翻譯，商家可手動檢查並修正用詞。
