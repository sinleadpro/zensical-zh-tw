溫層用於低溫商品(例如生鮮、冷凍食品),設定後顧客下單時只能選擇您為此商品綁定的溫層物流,避免常溫與冷凍商品混在同一張託運單。

### 運送溫層對照表 { #reference-product-temperature }

| 溫層 | 說明 |
| :-- | :-- |
| 常溫 | 一般商品的預設溫層,以常溫物流配送。 |
| 冷藏 | 需冷藏配送的商品,例如生鮮、乳製品。 |
| 冷凍 | 需冷凍配送的商品,例如冰品、冷凍食品。 |

!!! note "註釋"
    * 「運送溫層」與「物流配送設定」屬於開通功能，開通後才會出現在 **設定** 分頁。
    * 溫層綁定後不可為空;顧客結帳時僅能選擇與該商品溫層相符的物流。
