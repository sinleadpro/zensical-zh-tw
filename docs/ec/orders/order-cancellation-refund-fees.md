## 退款範圍與手續費返還

下表適用於取消訂單、退貨退款（全退）與退貨退款（部分退）：


### 一般版使用 CYBERBIZ PAYMENTS


| 退款情境 | 退款方式 | 金流手續費 | 人工退款手續費 |
| ------- | -------- | ---------- | ------------ |
| 取消訂單 | 系統自動退款 | 依退款金額比例返還 | 不收取 |
| | **商家自行匯款** | 不返還 | 收取 |
| 全額退款 | 系統自動退款 | 全額返還 | 不收取 |
| | **商家自行匯款** | 不返還 | 收取 |
| 部分退款 | 系統自動退款 | 依退款金額比例返還 | 不收取 |
| | **商家自行匯款** | 不返還 | 收取 |

    

### PLUS、企業版

=== "CYBERBIZ PAYMENTS"

    > **適用付款選項**：信用卡 / Apple Pay / Google Pay / 銀聯卡 / iPASS一卡通

    | 退款情境 | 退款方式 | 系統維護費 | 金流手續費 | 人工退款手續費 |
    | ------- | -------- | -------- | ---------- | ------------- |
    | 取消訂單 | 系統自動退款 | 依退款金額比例返還 | 依退款金額比例返還 | 不收取 |
    | | **系統人工退款** | 依退款金額比例返還 | 不返還 | 收取 |
    | 全額退款 | 系統自動退款 | 全額返還 | 全額返還 | 不收取 |
    | | **系統人工退款** | 全額返還 | 不返還 | 收取 |
    | 部分退款 | 系統自動退款 | 依退款金額比例返還 | 依退款金額比例返還 | 不收取 |
    | | **系統人工退款** | 依退款金額比例返還 | 不返還 | 收取 |


=== "LINE Pay / 街口支付"

### 跨境

=== "CYBERBIZ PAYMENTS"


    | 退款情境 | 退款方式 | 系統維護費 | 金流手續費 | 人工退款手續費 |
    | ------- | -------- | -------- | ---------- | ------------- |
    | 取消訂單 | 系統自動退款 | 依退款金額比例返還 | **不返還** | 不收取 |
    | | **商家自行匯款** | 依退款金額比例返還 | 不返還 | 收取 |
    | 全額退款 | 系統自動退款 | 全額返還 | **不返還** | 不收取 |

=== "其他金流"
    
    > **適用金流選項**：SoftBank、Fiuu

    | 退款情境 | 退款方式 | 系統維護費 | 人工退款手續費 |
    | ------- | -------- | -------- | ------------- |
    | 取消訂單 | 系統自動退款 | 依退款金額比例返還 | 不收取 |
    | | **商家自行匯款** | 依退款金額比例返還 | 收取 |

    | | **商家自行匯款** | 全額返還 | 收取 |
    | 部分退款 | 系統自動退款 | 依退款金額比例返還 | 不收取 |
    | | **商家自行匯款** | 依退款金額比例返還 | 收取 |



!!! note "比例返還計算方式"
    部分退款的比例返還金額，依 **退款金額 ÷ 訂單金額 × 原手續費** 計算。

## 人工退款手續費例外

下列情境不收取人工退款手續費：


| 例外情境 | 說明 |
| :--- | :--- |
| 電子票券訂單 | 票券類型訂單執行退款 |
| 爭議款退款 | 因爭議款執行退款 |
| 貨到付款未收貨 | 貨到付款訂單尚未完成收貨 |
| 商家自行改單金額 | 商家自行調整訂單金額後執行退款 |
