# 定期訂購訂單管理
當消費者在定期定額活動頁下單後，系統會產生一筆「母訂單」，並依據設定的週期（如每月、每週）自動產生「子訂單」。商家可透過後台管理這些訂閱關係與各期配送進度。
{ .subtitle }

[:lucide-tag:{ title="適用方案" }](../../resources/conventions#適用方案) | 所有 PLUS / 企業
{ .doc-badge }

!!! info "版本差異說明"
    - 「定期訂購」在 PLUS 方案中屬於選配模組（11 選 2），商家需確認已選配該模組方可使用。企業版則直接內建此功能。


## 使用須知

- **名詞定義**
    - **母訂單（定期單號）**：紀錄訂閱的整體規則，如商品組合、配送頻率、剩餘期數等。
    - **子訂單（一般訂單編號）**：每一期實際成立的配送訂單，用於出貨、收款與對帳。



## 定期訂單列表分類

登入 CYBERBIZ 管理後台，前往 **訂單 > 定期定額訂單**。

系統將定期訂單依狀態分為以下頁籤，方便商家快速排查：

| 頁籤名稱 | 說明 | 搜尋建議 |
| :--- | :--- | :--- |
| **所有顧客訂單** | 顯示所有已成立的母訂單 | 定期單號<br>收貨資訊（顧客、收件者地址、收件者聯絡電話）<br>備註 |
| **最新訂單** | 顯示所有顧客「最新一期」的子訂單 | 訂單編號<br>收貨資訊（顧客、收件者地址、收件者聯絡電話） |
| **待出貨** | 顯示目前已成立且準備出貨的子訂單 | 訂單編號<br>收貨資訊（顧客、收件者地址、收件者聯絡電話） |
| **已出貨** | 顯示已完成配送的子訂單 | 訂單編號<br>收貨資訊（顧客、收件者地址、收件者聯絡電話） |
| **訂單異常** | 顯示建立失敗（如庫存不足、信用卡扣款失敗）或貨態異常的訂單 | 訂單編號<br>收貨資訊（顧客、收件者地址、收件者聯絡電話） |
| **已取消** | 分為「整筆取消（母訂單）」與「部分取消（子訂單）」 | 定期單號<br>訂單編號 |

![](https://www.cyberbiz.co/support/wp-content/uploads/2019/11/定期定額new-14.png){ .screenshot }

## 查詢母子訂單關係

若想確認某一筆一般訂單是屬於哪一筆定期訂單的第幾期，可透過以下方式查看：

1. 前往 **訂單 > 所有訂單**。
2. 點擊右上角 **[編輯欄位](../orders/basics/order-management-interface/#編輯欄位與排序)**。
3. 勾選顯示 **母訂單編號**、**配送期數** 或 **實際配送次數**，即可查看訂單的定期配送資訊。


## 修改配送資訊

商家可針對「單一期數」或「整筆訂閱」進行配送資訊的調整。

### 1. 修改單一期數（子訂單）

在定期訂單列表中，直接點擊文字即可修改：

- **收件者資訊**：僅會更改該期訂單，後續期數維持原狀。
- **出貨日**：僅更改該期出貨時間。

### 2. 修改整筆訂閱（母訂單）

點擊 **定期單號** 進入明細頁面進行進階編輯。此處的修改將影響後續所有尚未成立的子訂單：

- **更改配送方案（時間）**：
  點擊「購買方案」旁的編輯圖示，根據原先設定的單位進行調整：

    - **以月為單位**：僅能更改「每幾週」及「每個星期幾」。
    - **以週為單位**：僅能更改「每個星期幾」。
    - **以每月特定日期為單位**：僅能更改「特定日期」。
    > **生效時間**：更改後會從「3 筆待成立訂單」的後一期開始套用。若要更改即將成立的訂單，請至「待成立訂單」區塊個別修改。
        ![](https://www.cyberbiz.co/support/wp-content/uploads/2019/11/定期定額new-32.png){ .screenshot }

    !!! warning "可以更改配送頻率嗎？"
        **不可以。** 系統不支援直接將「每月配送」改為「每週配送」。若需更改頻率，必須取消原母訂單，並引導顧客重新下單。

    
    ![](https://www.cyberbiz.co/support/wp-content/uploads/2019/11/定期定額new-26.png){ .screenshot }

- **更改商品內容**：
  在訂單明細區塊，您可以針對商品進行以下操作：

    - **編輯商品**：修改「商品數量」或「商品單價」。
    - **刪除商品**：移除特定商品款式。
    - **新增商品**：點擊「新增商品」按鈕，搜尋並加入其他商品款式至此定期訂單（新增後於下期訂單生效）。
    > **風險提醒**：若調整金額導致子訂單未達免運門檻，系統在轉單時會 **自動加收運費**。

    ![](https://www.cyberbiz.co/support/wp-content/uploads/2019/11/定期定額new-28.png){ .screenshot }



## 常見問題

??? quote "運費是如何計算的？"
    定期定額訂單預設 **抓取母訂單成立時的運費**。除非商家手動調整了子訂單的商品內容或金額，觸發系統重新判定免運門檻，否則運費不會變動。
