# 超商取貨姓名填寫規範
了解超商取貨（如 7-11）對於收件人姓名的填寫限制，包含字數長度、特殊字元、數字及空白的使用規則，避免因格式不符導致出貨拋單失敗。
{ .subtitle }


!!! tip "應用情境"
	- **結帳即時驗證**：顧客在結帳頁面填寫收件人姓名時，系統會依據此規則進行即時檢查。
	- **出貨異常排除**：當訂單狀態顯示「出貨失敗」且原因與姓名相關時，可用於核對並修正收件人資訊。


## 使用須知

- **規範目的**：為確保訂單資訊能成功對接超商物流系統（如 7-11 拋單），系統對收件人姓名設有嚴格的格式限制。


## 姓名填寫規則

### 1. 長度限制

系統會區分 **中文** 與 **英文** 字元，分別計算長度。

| 類型 | 長度上限 | 長度下限（符合其一即可） |
| :--- | :--- | :--- |
| **中文字** | 最多 **5** 個字 | 至少 **2** 個中文字 |
| **英文字** | 最多 **10** 個字 | 至少 **4** 個英文字 |
| **中英混和** | - | 至少 **1 個中文字 + 2 個英文字** |

!!! example "範例說明"
    - **通過**：`王小明` (3中)、`John` (4英)、`王Aa` (1中2英)。
    - **不通過**：`王` (太短)、`王小明張李陳` (中文超過 5 字)。

### 2. 禁止使用的字元

為避免物流系統解析錯誤，姓名欄位禁止包含以下任何字元：

- **半形/全形特殊符號**：如 `!`, `@`, `#`, `$`, `。`, `、`, `「`, `」` 等。
- **Emoji 表情符號**：如 😀, ❤️, 🎉 等。
- **注音符號**：包含注音字母（ㄅㄆㄇ）及聲調符號（ˇˋˊ˙）。

### 3. 數字使用限制

是否允許包含數字，取決於該訂單的 **付款方式**：

| 付款方式 | 是否允許含數字 | 原因說明 |
| :--- | :--- | :--- |
| **貨到付款** | **允許** | 取件流程不需核對身分證件，限制較寬鬆 |
| **非貨到付款** | **不允許** | 需核對身分證件，數字通常非正式姓名的一部分 |


### 4. 空白處理

系統會自動處理姓名欄位中的空白字元：

- **前後空白**：系統會自動移除。
- **中間空白**：系統會自動移除。例如輸入 `王 小明`，系統將自動儲存為 `王小明`。



## 案例參考

若商家或客服需協助顧客排查姓名問題，可參考下表之驗證結果：

| 輸入內容 | 驗證結果 | 錯誤訊息提示 | 
| :--- | :--- | :--- | 
| `賴.` | 失敗 | 不能包含特殊字元 | 
| `王小明張李陳` | 失敗 | 姓名長度不符 | 
| `😀賴` | 失敗 | 不能包含 Emoji | 
| `王` | 失敗 | 姓名長度不符 | 
| `王ㄇ明` | 失敗 | 不能包含注音符號 | 
| `John123`（非貨到付款訂單） | 失敗 | 不能包含數字 | 
| `Tony1`（貨到付款訂單） | **成功** | - |
