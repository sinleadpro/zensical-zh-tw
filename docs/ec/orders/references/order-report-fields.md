## 訂單各項折扣拆分


| 商品折扣欄位 | 說明 | 備註 |
| :--- | :--- | :--- |
| 商品任選折扣總金額 | 針對「任選 X 件 Y 折」或「任選滿額折」活動之折抵總額 | |
| 商品全館折扣金額 | 套用全站促銷活動（如全館 9 折）所分攤的折扣金額 | |
| 商品 VIP 折扣總金額 | 根據會員等級（VIP/VVIP）設定之優惠所產生的折扣 | |
| 商品優惠券折扣總金額 | 顧客於結帳使用優惠券（Coupon）後分攤之金額 | |
| 商品紅利折扣總金額 | 顧客使用紅利點數（Points）進行現金折抵之金額 | |
| 商品店長改價折扣總金額 | 由門市人員於結帳時手動修改價格產生的折扣差額 | **POS 限定** |
| 商品單品折扣總金額 | 針對單一商品直接設定特價與原價之間的差額 | |
| 商品組合優惠折扣總金額 | 針對「組合商品（A+B）」活動所產生的優惠折扣 | |
| 商品分類優惠折扣總金額 | 針對特定分類設定之滿額/滿件折扣（含多層級） | |
| 商品第三方折扣總金額 | 來自外部串接平台（如 LINE 購物）之專屬折抵 | |
| 商品遊戲折扣總金額 | 透過行銷互動遊戲（如轉盤、刮刮卡）獲得之折抵 | |
| 商品會員專屬價格折扣總金額 | 針對特定會員身份直接設定的「固定專屬價」與原價價差 | |

## UTM 參數


| UTM 參數名稱 | 系統對應欄位 | 說明 |
| :--- | :--- | :--- |
| **「UTM 來源」** | `utm_source` | 流量的來源平台，例如：google, facebook, newsletter |
| **「UTM 活動名稱」** | `utm_campaign` | 特定的促銷活動或產品推廣名稱，例如：spring_sale |
| **「UTM 媒介」** | `utm_medium` | 行銷的媒介類型，例如：cpc, email, social |
| **「UTM 活動字詞」** | `utm_term` | 通常用於關鍵字廣告，標記搜尋的關鍵字 |
| **「UTM 點擊時間」** | `utm_click_time` | 顧客點擊該追蹤連結並進入網站的具體時間紀錄 |
| **「UTM 活動內容」** | `utm_content` | 用於區分相同連結的不同版本（A/B 測試），例如：logolink, textlink |


## 組合品價差

### 計算步驟

1.  **計算總價差**：「商品原始售價總金額」 - 「組合品售價」
2.  **計算「組合品價差」**：依子商品類型計算讓利金額。  
      
    1.  按原價比例攤提：「組合品總價差」ｘ「各子商品原價比例」。
    2.  將小數點無條件捨去至整數位。若小數點捨去後，有剩餘未分配的折扣金額，系統將依據子商品的排序，以 1 元為單位逐一分配補足。
  
3.  **計算「組合品價差明細」**：若某個子商品品項的數量為複數時，進一步將該品項的總折金額，攤提至每一件單品上。  
      
    1.  按商品數量攤提：「組合品價差」÷「子商品數量」。
    2.  將小數點無條件捨去至整數位。若小數點捨去後，有剩餘未分配的折扣金額，系統將依據子商品的排序，以 1 元為單位逐一分配補足。


### 範例 1 ：每種子商品各 1 件

假設您建立了 1 組售價 850 元 的組合品，內含以下 3 件子商品：

- 子商品 A：原價 100 元
- 子商品 B：原價 300 元
- 子商品 C：原價 500 元

#### 計算步驟

1. **算出總價差**

    子商品原總售價為 100 + 300 + 500 = 900 元

    900 元（原總價）－ 850 元（組合價）＝ 50 元（總價差）

2. **算出「組合品價差」**

    1. **按比例攤提**

        - 子商品 A：50 × [ 100 / 900 ] = 5.56 元 ➔ 捨去後為 5 元
        - 子商品 B：50 × [ 300 / 900 ] = 16.67 元 ➔ 捨去後為 16 元
        - 子商品 C：50 × [ 500 / 900 ] = 27.78 元 ➔ 捨去後為 27 元

    2. **剩餘尾數分配**

        目前已分配折扣：5 + 16 + 27 = 48 元。
        
        剩餘未分配折扣為 50 － 48 ＝ 2 元。依據 A、B、C 的商品順序，個別塞入 1 元：

        - 子商品 A：獲得 1 元 ➔ 最終價差為 6 元
        - 子商品 B：獲得 1 元 ➔ 最終價差為 17 元
        - 子商品 C：分配結束 ➔ 最終價差維持 27 元

3. **算出「組合品價差明細」**

    組合品內的子商品數量皆為 1，「該品類的價差」即為「單件讓利金額」，系統無須再另行拆解單個品項的折讓明細。

#### 報表呈現方式

| 商品名稱 | 組合品價差 | 組合品價差明細 |
| ------- | ---------- | ------------ |
| 子商品 A | 6 | [6] |
| 子商品 B | 17 | [17] |
| 子商品 C | 27 | [27] |

> 此表格僅列出範例相關欄位，其餘報表欄位已省略。

### 範例 2：單一子商品包含複數件

假設您建立了 1 組售價 777 元 的組合品，內含以下 4 件子商品：

- 子商品 A：原價 166 元 × 1 件
- 子商品 B：原價 250 元 × 3 件 （此子商品為複數件）

當消費者購買組合品 2 組時，計算步驟如下：

#### 計算步驟

1. **算出總價差**

    組合總售價 = 777 × 2 = 1,554 元

    單組原總價 = 166 + 250 × 3 = 916 元；2 組原總售價 = 916 × 2 = 1,832 元

    1,832 元（2組原總價）－ 1,554 元（2組組合價）＝ 278 元（總價差）

2. **算出「組合品價差」**

    1. **按比例攤提**

        - 子商品 A：278 × [ (166 × 2) / 1,832 ] = 50.36 元 ➔ 捨去後為 50 元
        - 子商品 B：278 × [ (750 × 2) / 1,832 ] = 227.63 元 ➔ 捨去後為 227 元

    2. **剩餘尾數分配**

        目前已分配折扣：50 + 227 = 277 元

        剩餘未分配折扣為 278 － 277 ＝ 1 元。依據商品順序分配：

        - 子商品 A：獲得 1 元 ➔ 最終總價差為 50 + 1 = 51 元
        - 子商品 B：最終總價差維持 227 元 ➔ **子商品數量為複數，繼續平攤每支品項的讓利金額**

3. **算出「組合品價差明細」**

    1. **按比例攤提**

        - 子商品 B-1：227 ÷ 3 = 75.6 元 ➔ 捨去後為 75 元
        - 子商品 B-2：227 ÷ 3 = 75.6 元 ➔ 捨去後為 75 元
        - 子商品 B-3：227 ÷ 3 = 75.6 元 ➔ 捨去後為 75 元

    2. **剩餘尾數分配**

        目前已分配折扣：75 + 75 + 75 = 225 元
        
        剩餘未分配折扣為 227 － 225 ＝ 2 元。依據商品順序分配：

        - 子商品 B-1：獲得 1 元 ➔ 最終價差為 75 + 1 = 76 元
        - 子商品 B-2：獲得 1 元 ➔ 最終價差為 75 + 1 = 76 元
        - 子商品 B-3：分配結束 ➔ 最終價差維持 75 元

#### 報表呈現方式

| 商品名稱 | 組合品價差 | 組合品價差明細 |
| ------- | ---------- | ------------ |
| 子商品 A | 51 | [51] |
| 子商品 B | 227 | [76,76,75] |

> 此表格僅列出範例相關欄位，其餘報表欄位已省略。
