## 付款狀態對照表 { #payment-statuses }

| 付款狀態 | 說明 |
| :-- | :-- |
| 等待付款 | 訂單成立但顧客尚未完成付款,常見於 ATM 轉帳、超商代碼繳費等待繳費期間 |
| 已收到款項 | 顧客已完成付款且款項已入帳 |
| 貨到付款 | 顧客選擇貨到付款,款項將於配送時由物流代收 |
| 已回填帳號未收款 | 顧客已回填匯款帳號後 5 碼,但商家尚未確認入帳 |
| 付款失敗 | 付款流程中斷或被金流方拒絕,例如信用卡授權失敗 |
| 會員棄單 | 顧客未完成付款且訂單已逾期作廢 |
| 除會員棄單以外 | 篩選快捷鍵:一次選取所有「非棄單」的訂單 |
| 客服處理中 | 該訂單因金流／退款問題進入客服人工處理階段 |
| 待退款 | 已確認需退款但款項尚未退出 |
| 退款中 | 退款流程進行中(已送出退款指令,等待金流回應) |
| 已退款 | 全額退款已完成 |
| 退款失敗 | 退款流程失敗,需人工處理 |
| 待部分退款 | 已確認需部分退款但款項尚未退出 |
| 部分退款 | 部分金額退款已完成(例如顧客退掉訂單中部分商品) |
| 不退款 | 訂單已標記為不進行退款(例如顧客同意換貨而非退款) |

!!! note "註釋"
    * 「等待付款」與「付款失敗」的訂單,都會被「訂單自動取消」機制納入,超過設定天數未付款成功即自動取消。
    * 貨到付款訂單的款項於顧客取貨付款後才認列,不適用線上付款失敗的處理流程。
    * 「除會員棄單以外」為列表篩選用的快捷選項,非單一訂單會出現的狀態。
