# 廣告分析指標對照表

本頁彙整「廣告分析」頁面中，數據總覽卡片與每日趨勢圖共用的 11 項成效指標。各指標的數據皆來自 Google 購物廣告(自動化廣告系統)，以每日為單位彙整。

---

### 成效指標對照表 { #reference-advertising-analytics-metrics }

| 指標 | 代表意義 | 計算方式 |
| :-- | :-- | :-- |
| 費用 | 廣告花費的成本。 | — |
| 曝光數 | 廣告出現(放送)的次數。 | — |
| 點擊數 | 只要顧客按下廣告，就會計算一次點擊。 | — |
| 點擊率 | 顧客點擊廣告的機率。 | 點擊數 ÷ 曝光數 |
| 平均點擊成本 | 平均一個點擊所花費的成本。 | 費用 ÷ 點擊數 |
| 轉換數 | 顧客點擊廣告後的下單次數[^conversion]。 | — |
| 轉換率 | 顧客下單的機率。 | 轉換數 ÷ 點擊數 |
| 平均轉換成本 | 平均一個轉換所花費的成本。 | 費用 ÷ 轉換數 |
| 轉換營收 | 顧客下單的訂單金額總和。 | — |
| 平均轉換客單價 | 平均一個轉換的訂單金額。 | 轉換營收 ÷ 轉換數 |
| ROAS | 廣告的投資報酬率，數字越高代表每一元廣告費帶回的營收越多。 | 轉換營收 ÷ 費用 |

!!! note "註釋"
    * 「點擊率」「轉換率」以百分比(%)顯示；「費用」「平均點擊成本」「平均轉換成本」「轉換營收」「平均轉換客單價」以金額顯示；其餘為次數。
    * 同樣的 11 項指標，會同時出現在上方的「數據總覽」卡片與下方的「每日趨勢圖」，差別只在於前者是區間加總、後者是逐日變化。
    * 將滑鼠移到每張數據卡片的名稱旁，可看到該指標的說明提示。

[^conversion]: 顧客在下單前 30 天內有點擊過廣告，就會計算為一次轉換。因此廣告開始投放後，需等待一段時間才會有轉換數據產生，且轉換可能歸屬到較早的點擊日期。
