# 基準參考範圍狀態對照表

### 基準參考範圍狀態對照表 { #reference-chart-overview-benchmark-status }

| 狀態 | 代表意義 | 建議動作 |
| :-- | :-- | :-- |
| 優於基準 | 此指標高於同業基準範圍 | 維持現有做法，並複製成功經驗到其他指標 |
| 符合基準 | 此指標落在同業基準範圍內 | 表現穩定，可視行有餘力再進一步優化 |
| 低於基準 | 此指標低於同業基準範圍 | 優化效益相對較高，建議列為優先改善項目 |

!!! note "註釋"
    * 基準參考範圍與狀態標籤為 **企業版** 專屬功能，且商家所屬產業需屬於支援類別才會顯示。
    * 「低於基準」會以紅色標示，提醒此指標有較大的成長空間。
    * 基準值來自「相似類別、同等表現商家之統計」，為同業彙整的參考區間，而非單一店家數字。
