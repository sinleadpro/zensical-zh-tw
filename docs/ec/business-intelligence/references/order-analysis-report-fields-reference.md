「訂單報表」分頁提供三張可下載成 Excel 的表格，以下說明各表的欄位意義。

### 日期區間對比 { #reference-order-analysis-report-compare }

設定「查詢日期區間」與「對比日期區間」兩段時間，系統會自動算出兩段之間的成長率(%)。

| 欄位 | 說明 |
| :-- | :-- |
| 訂單數量 | 該區間內的認列訂單筆數。 |
| 購買會員數 | 該區間內實際下單的會員人數。 |
| 銷售金額 | 該區間內的認列訂單總金額。 |
| 訂單客單價 | 銷售金額 ÷ 訂單數量，代表平均每筆訂單的金額。 |
| 會員客單價 | 銷售金額 ÷ 購買會員數，代表平均每位會員的消費金額。 |
| 成長率(%) | 「查詢日期區間」相對於「對比日期區間」的成長比率，正值為成長、負值為衰退。 |

---

### 時間別業績狀況 { #reference-order-analysis-report-by-time }

以「時段」為單位，觀察一天當中不同時段的接單狀況，適合評估廣告投放或促銷活動的最佳時機。

| 欄位 | 說明 |
| :-- | :-- |
| 時段 | 時間區段。 |
| 訂單數量(等待付款／已付款／貨到付款／總計) | 各時段的訂單筆數，並依付款狀態分欄統計。 |
| 銷售金額(等待付款／已付款／貨到付款／總計) | 各時段的訂單金額，並依付款狀態分欄統計。 |

---

### 每日業績狀況 { #reference-order-analysis-report-daily }

以「日期」為單位，列出查詢區間內每一天的業績明細。

| 欄位 | 說明 |
| :-- | :-- |
| 日期 | 統計的日期。 |
| 訂單數量(等待付款／已付款／貨到付款／總計) | 當日的訂單筆數，並依付款狀態分欄統計。 |
| 銷售金額(等待付款／已付款／貨到付款／總計) | 當日的訂單金額，並依付款狀態分欄統計。 |
| 客單價(等待付款／已付款／貨到付款／總計) | 當日的平均每筆訂單金額，並依付款狀態分欄統計。 |

!!! note "註釋"
    * 三張表都可透過表格右上角的 **「下載為Excel」** 按鈕匯出。
    * 「等待付款、已付款、貨到付款」為付款狀態分類，「總計」為三者加總。
