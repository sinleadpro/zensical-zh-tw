# 會員等級銷售狀況對照表

「會員總覽」分頁的「期間別會員等級銷售狀況」，將會員依等級分為兩類，比較各自的銷售貢獻。

### 會員等級對照 { #reference-member-levels }

| 等級 | 從商家視角看代表什麼 |
| :-- | :-- |
| VIP會員 | 已達到您所設定的 VIP 條件、升級為 VIP 的會員 |
| 普通會員 | 尚未達到 VIP 條件的一般會員 |

!!! note "註釋"
    * VIP 與普通會員的分界，取決於您在會員分級設定中所訂的門檻（例如累積消費金額或消費次數），本報表只是依該設定統計兩群的銷售狀況。
    * 透過比較 VIP 與普通會員的銷售貢獻，可評估目前 VIP 門檻與會員制度是否有效。若 VIP 貢獻明顯偏高，代表分級制度發揮了集中經營主力客群的效果。
