# 折扣種類對照表 { #reference-marketing-activity-discount-categories }

「折扣活動分析」中的「折扣種類分析」與「折扣活動排名」會依折扣種類分類統計。目前系統提供以下 5 種折扣種類：

| 折扣種類 | 說明 | 開通條件 |
| :-- | :-- | :-- |
| 訂單加價購 | 顧客結帳時，整筆訂單達指定條件即可加價購買指定商品。 | 需先啟用「訂單加價購」行銷活動功能 |
| 商品加價購 | 顧客購買指定商品時，可加價購買搭配的商品。 | 需先啟用「商品加價購」行銷活動功能 |
| 紅配綠多組合優惠折扣 | 多件商品組合達指定條件時給予折扣。 | 需先啟用「紅配綠多組合優惠折扣」行銷活動功能 |
| 優惠碼折扣 | 顧客於結帳時輸入優惠碼即享折扣。 |  |
| 任選折扣 | 指定商品中任選指定件數即享折扣。 |  |

!!! note "註釋"
    * 「訂單加價購」、「商品加價購」、「紅配綠多組合優惠折扣」需先啟用對應的行銷活動功能，下拉選單才會出現該種類；未啟用時不會顯示。
    * 「優惠碼折扣」與「任選折扣」為內建功能，所有可使用本頁的方案皆可看到。
