# 會員現況與註冊來源對照表

「會員總覽」分頁的「會員現況」區塊，依會員的註冊狀態與登入來源分類統計。各分類意義如下。

### 會員現況分類對照 { #reference-member-registration-sources }

| 分類 | 從商家視角看代表什麼 |
| :-- | :-- |
| 新會員 | 統計區間內新加入的會員 |
| 舊會員 | 統計區間之前即已加入、本期仍在名單內的會員 |
| 註冊會員 | 已完成註冊、留下會員資料的顧客 |
| 未註冊會員 | 曾下單但未完成註冊（以訪客或快速結帳留下資料）的顧客 |
| FB登入會員 | 透過 Facebook 快速登入加入的會員 |
| LINE登入會員 | 透過 LINE 快速登入加入的會員 |
| 已綁定LINE@會員 | 已將帳號與您商店官方 LINE 綁定的會員 |

!!! note "註釋"
    * 「FB登入會員」、「LINE登入會員」、「已綁定LINE@會員」需要您的商店有啟用對應的第三方登入或 LINE 綁定功能，顧客才會被歸入這些來源；若未啟用，對應數字會是 0。
    * 同一位會員可能同時符合多種來源（例如以 LINE 登入又綁定官方 LINE@），請以各區塊的統計說明為準。
