### 關鍵數字與趨勢圖 { #reference-order-analysis-overview-metrics }

| 指標／圖表 | 商家視角說明 |
| :-- | :-- |
| 總訂單數 | 網站開站至今累計的認列訂單總數。 |
| 近30日訂單數 | 最近 30 天的認列訂單數,用來快速掌握近一個月的業績量。 |
| 訂單數月趨勢 | 指定區間內每個月的訂單數量變化折線圖。 |
| 單筆訂單金額月趨勢 | 將每月訂單依金額區間(如 0~1000 元、3001~5000 元)分群,觀察各區間的筆數變化。 |
| 單筆訂單金額月趨勢 比例 | 同上,改以百分比堆疊呈現各金額區間的占比。 |
| 單筆訂單金額(訂單總數占比) | 整段期間內,各金額區間占全部訂單的比例圓餅圖,協助設定客單價目標。 |
| 單筆訂單商品數(訂單總數占比) | 顧客一筆訂單通常買幾樣商品的占比圓餅圖(含加價購、滿額贈)。 |
| 每日平均訂單數量(月趨勢) | 每月「平均每日訂單數」的趨勢圖。 |
| 近30日日均訂單數 | 最近 30 天平均每日成立幾筆訂單。 |
| 變動值(日均訂單數) | 近 30 日的日均訂單數,相對於長期平均的成長數值。 |
| 每日平均訂單金額(月趨勢) | 每月「平均每日訂單金額」的趨勢圖。 |
| 近30日平均訂單金額 | 最近 30 天平均每日的訂單金額。 |
| 變動值(平均訂單金額) | 近 30 日的平均訂單金額,相對於長期平均的成長數值。 |
| 訂單取消率月趨勢 | 每月訂單取消率的趨勢圖,用來監控營運異常。 |
| 近30日訂單取消率 | 最近 30 天的訂單取消比率。 |
| 變動值(訂單取消率) | 近 30 日取消率相對於長期平均的成長比率。 |
| 訂單退貨率月趨勢 | 每月訂單退貨率的趨勢圖。 |
| 近30日訂單退貨率 | 最近 30 天的訂單退貨比率。 |
| 變動值(訂單退貨率) | 近 30 日退貨率相對於長期平均的成長比率。 |

!!! note "註釋"
    * 標示為「變動值」的卡片,比較的是 **過去 30 日** 與 **長期平均** 兩個數值,正值代表近期成長、負值代表近期下滑。
    * 退貨率的計算會先排除已取消的訂單,再以認列訂單為母數統計,定義詳見主文「重要規範與限制」。
