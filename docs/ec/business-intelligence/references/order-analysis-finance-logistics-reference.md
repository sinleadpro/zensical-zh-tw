### 三個分析群組 { #reference-order-analysis-finance-logistics }

「訂單金物流分析」分頁把訂單依三種角度拆解,每個角度都提供「訂單數趨勢、訂單占比、平均客單價、退貨率」四類圖表。

| 分析群組 | 提供的圖表 | 商家視角說明 | 顯示條件 |
| :-- | :-- | :-- | :-- |
| 付款方式 | 訂單數趨勢、訂單占比、平均客單價、退貨率 | 比較各種付款方式(如信用卡、貨到付款、LINE Pay、超商付款等)的訂單量、占比與退貨表現,找出高效益或高風險的金流管道。 | 進入此分頁即顯示。選項依商家實際開通的付款方式動態呈現。 |
| 出貨方式 | 訂單數趨勢、訂單占比、平均客單價、退貨率 | 比較各種出貨方式(如宅配、超商取貨、店到店等)的訂單表現,協助評估物流成本與顧客便利性。 | 進入此分頁即顯示。選項依商家實際開通的出貨方式動態呈現。 |
| 第三方導購 | 訂單數趨勢、訂單占比、平均客單價、退貨率 | 觀察來自導購平台的訂單筆數、占比與平均客單價,評估導購成效。 | 需商店已串接導購平台才會出現,詳見下方註釋。 |

!!! note "註釋"
    * **第三方導購** 的圖表,只有在商店符合以下任一條件時才會顯示:已設定「美安夥伴商店」、已串接「通路王」、或已串接「LINE購物」。三者皆未啟用時,整組第三方導購圖表不會出現。
    * 各圖表的「平均客單價」是以該群組的營業額除以對應訂單數計算。
    * 退貨率與取消的排除規則,與整體報表一致,定義詳見主文「重要規範與限制」。
