# 會員分析共用定義

會員分析頁面「會員總覽」、「會員分析」、「消費顧客分析」三個分頁共用的統計基準與名詞定義，集中整理於此，供各篇教學以連結引用。
{ .subtitle }

### 有效訂單定義 { #reference-member-valid-order }

會員分析頁面上方標示了「有效訂單定義」，頁面所有數字皆以「有效訂單」為計算基礎。有效訂單須同時符合下列兩個條件：

- [x] **訂單狀態**：為非取消訂單。
- [x] **退貨狀態**：為不需退貨或拒絕退貨。

也就是說，已取消、已退貨的訂單 **不會** 計入會員分析的各項數字。這也是頁面數字可能與訂單列表總金額不一致的主要原因。

!!! note "註釋"
    部分圖表（例如「會員平均認列訂單數」、「新會員下單率（認列訂單）」）以「認列訂單」為基礎，認列訂單的判定條件與上述有效訂單相同：非取消訂單，且退貨狀態為不需退貨或拒絕退貨。

---

### 數據更新時間 { #reference-member-update-time }

會員分析的數字並非即時統計，而是定時批次更新：

- **流量、轉換率數據**：於隔日下午五點半更新。
- **其餘數據（含會員相關數據）**：於隔日凌晨零點更新；取消及退貨訂單會定時更新排除。

!!! note "註釋"
    因為是隔日更新，本頁數字通常反映到「前一天」為止，當天剛成立的訂單與剛註冊的會員不會立即出現，屬正常現象。

---

### 新會員與新客的兩種定義 { #reference-member-new-definitions }

CYBERBIZ 在不同分頁使用兩套「新 / 舊」的判定邏輯，基準並不相同，解讀數字前請先確認您正在看哪一個分頁：

| 分頁 | 名稱 | 判定方式 |
| :-- | :-- | :-- |
| 會員分析 | 新會員 | 在「該月份內新註冊」的會員，視為當月新會員（以註冊時間為準） |
| 消費顧客分析 | 累積顧客數 | 開店截至指定時間結束前，曾經下單的顧客數 |
| 消費顧客分析 | 消費顧客數 | 第一次下單發生在指定時間內的顧客數 |
| 消費顧客分析 | 消費新客數 | 第一次下單發生在指定時間內的顧客 |
| 消費顧客分析 | 消費舊客數 | 過去已有下單紀錄，且在指定時間內又再次下單的顧客 |

!!! tip "技巧"
    簡單記：「會員分析」的新舊以 **註冊時間** 為準；「消費顧客分析」的新舊以 **第一次下單時間** 為準。同一位顧客在兩個分頁可能被歸到不同類別，這是定義不同所致，並非數據錯誤。
