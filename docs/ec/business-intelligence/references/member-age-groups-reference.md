# 會員年齡分群對照表

「會員總覽」分頁的「會員年齡分群」依會員生日換算的年齡，分為以下區間統計。

### 年齡區間對照 { #reference-member-age-groups }

| 年齡區間 | 說明 |
| :-- | :-- |
| 19歲以下 | 換算年齡未滿 20 歲 |
| 20-29 | 20 至 29 歲 |
| 30-39 | 30 至 39 歲 |
| 40-49 | 40 至 49 歲 |
| 50-59 | 50 至 59 歲 |
| 60-69 | 60 至 69 歲 |
| 70歲以上 | 70 歲（含）以上 |
| 未填寫 | 會員未填寫生日，無法換算年齡 |

!!! note "註釋"
    * 年齡是依會員填寫的生日 **即時換算** 而得，並非註冊當下的年齡。
    * 未填寫生日的會員會集中歸入「未填寫」，若此類佔比偏高，代表多數會員尚未補齊生日資料，可在會員經營時引導填寫以提升分群精準度。
