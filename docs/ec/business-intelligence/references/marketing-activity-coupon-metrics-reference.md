# 優惠券指標定義對照表 { #reference-marketing-activity-coupon-metrics }

「優惠券分析」分頁的數字卡指標定義如下，分為「種類分析」與「特定優惠券分析」兩組。所有指標僅計算 **有效訂單**。

### 優惠券種類分析指標 { #reference-marketing-activity-coupon-metrics-category }

| 指標 | 定義 |
| :-- | :-- |
| 平均折扣金額 | 使用該分類優惠券的折扣總金額 ÷ 使用該分類優惠券的訂單總數量。 |
| 折扣金額 | 使用該分類優惠券的折扣總金額。 |
| 平均折扣比例 | 使用該分類優惠券的折扣總金額 ÷ 使用該分類優惠券之訂單未折抵行銷活動前的總金額(不包含運費)。 |
| 優惠券使用次數 | 該分類優惠券被使用的次數(取消訂單會歸還優惠券，該次使用不列入計算)。 |
| 平均訂單金額 | 使用該分類優惠券的訂單總營業額 ÷ 使用該分類優惠券的訂單總數量。 |
| 優惠券訂單營業額 | 使用該分類優惠券的訂單總營業額。 |
| 平均使用週期(天) | 該分類優惠券從發送至會員帳戶到實際使用的平均間隔天數。 |
| 優惠券發放數量 | 當日官網「可供使用」的優惠券張數。系統每日會自動統計以下來源：今天發放的優惠券、今天之前發放但到今天仍然有效的優惠券。 |
| 優惠券已使用數量 | 當日官網「於有效期內且被認列為已使用」的優惠券數量。當消費者於優惠券有效期間內成功使用該券時，從使用日開始直到優惠券到期前的每一天，皆會計入當日已使用數量（數量為 1）。一旦優惠券到期，不再計入後續日期的已使用數。 |
 
---

### 特定優惠券分析指標 { #reference-marketing-activity-coupon-metrics-specific }

| 指標 | 定義 |
| :-- | :-- |
| 折扣金額 | 使用該張優惠券的折扣總金額。 |
| 平均折扣比例 | 使用該張優惠券的折扣總金額 ÷ 使用該張優惠券之訂單未折抵行銷活動前的總金額(不包含運費)。 |
| 平均訂單金額 | 使用該張優惠券的訂單總營業額 ÷ 使用該張優惠券的訂單總數量。 |
| 優惠券訂單營業額 | 使用該張優惠券的訂單總營業額。 |
| 優惠券使用次數 | 該張優惠券被使用的次數(取消訂單會歸還優惠券，該次使用不列入計算)。 |
| 優惠券使用率 | 該張優惠券被使用的次數 ÷ 該張優惠券的發送數量。 |
| 平均使用週期(天) | 該張優惠券從發送至會員帳戶到實際使用的平均間隔天數。 |
| 目標客群數 | 擁有此張優惠券的會員數量(相同優惠券不重複計算)。 |
| 目標客群總營業額 | 擁有此張優惠券的會員，在此時間區間內的消費總金額(無論是否使用優惠券皆列入計算)。 |
