## 什麼是 CYBERBIZ APP

  
官網 APP 是 CYBERBIZ 提供的行動應用服務，協助商家將 **線上官網** 延伸至消費者的手機裝置，建立可主動溝通、可持續經營會員關係的品牌接觸管道。  
  

### 產品亮點總覽
  

1.  **線上官網 × 線下消費者的溝通渠道**  
    *   透過手機 APP 作為品牌固定入口
    *   降低消費者回訪官網的操作成本
  
3.  **會員池經營機制**  
    *   整合會員卡、優惠券與紅利點數
    *   支援會員權益顯示與使用情境
  
5.  **訊息推播通知**  
    *   支援活動、訂單與會員相關訊息推播
    *   作為官網以外的即時通知管道

### 此功能適合哪些商家 
  
若您有以下經營需求，官網 APP 可作為輔助工具：  
  

*   希望建立 **穩定且可重複觸達** 的消費者溝通管道
  
*   已開始經營或計畫經營 **會員制度**（會員卡、優惠券、紅利點數）
  
*   需要透過 **推播訊息**，主動通知會員活動、訂單或權益資訊

## APP 常見操作
  

### 訊息通知

<div class="grid cards" markdown>

-   ![](https://www.cyberbiz.io/support/wp-content/uploads/手機鎖定螢幕-APP彈窗通知01.jpg){ .mini-image }

    **鎖定螢幕彈窗通知** 

    - 位置：手機鎖定螢幕

-   ![](https://www.cyberbiz.io/support/wp-content/uploads/EC-前台-APP介面-首頁-通知列表01.jpg){ .mini-image }

    **App內小鈴鐺通知列表**  
  

    - 位置：App首頁 → 點擊 :lucide-bell:

</div>

`使用情境`

- 當App進行推播通知時，使用者可於鎖定螢幕收到通知。
- App 內的小鈴鐺同步顯示通知，使用者點擊後即可查看該帳號收到的所有歷史通知。



<div class="grid cards" markdown>

-   ### 網站瀏覽
    
    ![](https://www.cyberbiz.io/support/wp-content/uploads/EC-前台-APP介面-首頁-搜尋01.jpg){ .mini-image }

    **搜尋**  

    - 位置：App首頁 → 點擊搜尋欄

    `使用情境`

    - 使用者瀏覽網站時，隨時可點擊搜尋框查找指定品項。

-   ### 線下結帳

    ![](https://www.cyberbiz.io/support/wp-content/uploads/EC-前台-APP介面-首頁-顯示會員條碼01.jpg){ .mini-image }

    **顯示會員條碼**  

    - 位置：App首頁 → 點擊條碼icon

    `使用情境`

    *   當消費者於線下門市結帳時，可引導消費者下載並開啟App，一鍵顯示會員條碼，即可掃碼登入會員，無須以手機號碼報號。
    *   為確保線下會員資料能精確同步，**此功能需搭配 CYBERBIZ POS 系統使用**。


</div>
