# CYBERBIZ APP

將線上官網延伸至手機裝置，透過推播、門市地圖與首登禮等功能，建立可重複觸達的會員經營管道。
{ .subtitle }

[:lucide-grid-2x2-plus:{ title="適用擴充" }](../../resources/conventions.md#適用擴充) | CYBERBIZ APP
{ .doc-badge }

!!! tip "應用情境"
    - **固定品牌入口**：以手機 APP 作為官網延伸，降低會員回訪成本。
    - **主動觸達會員**：透過推播發送訂單、活動與權益通知。
    - **促進下載與首登**：搭配首登禮，提升 APP 下載與首次登入轉換。

官網 APP 承襲網頁版視覺與商品資料，並整合會員卡、優惠券與紅利點數。建議依下列順序完成認識、建置與經營設定。

<div class="grid cards" markdown>

-   :lucide-settings:{ .lg .middle }
    __建置與管理__

    ---

    完成上架前環境準備與官網預建置，並設定 APP 門市地圖、系統通知樣板與活動推播。

    [:octicons-arrow-right-24: 前往](setup-cyberbiz-app.md)

-   :lucide-badge-check:{ .lg .middle }
    __申請 Apple 開發者帳號__

    ---

    上架 iOS APP 前，申請 Apple Developer Program、取得鄧白氏編碼，並於 App Store Connect 授權 CYBERBIZ。

!!! info "上架說明"
    - **Apple Store（iOS）**：需自行申請開發者帳號並授權 CYBERBIZ。
    - **Google Play（Android）**：由 CYBERBIZ 提供 Google 開發者帳號，無需自行申請。
