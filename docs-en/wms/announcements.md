# Announcements
Keep up with system updates for the e-commerce warehouse system (WMS), important changes to warehouse operations, and the status of system bug fixes.
{ .subtitle }

[:lucide-layers:{ title="Applicable Products" }](../../resources/conventions#適用產品) | Smart Warehousing
{ .doc-badge }

![](../assets/images/WMS-後台-公告-畫面總覽01.en.png){ .hero-page }

## Announcement Types { #overview-announcements-types }

System announcements fall into three types, so you can quickly tell what each one affects:

- **Admin Update**: Covers WMS interface improvements, new features, and changes to how tasks are done.
- **Operator Update**: Covers operating notices from the physical warehouse, such as receiving changes over long holidays, stocktaking date reminders, or major logistics changes.
- **BUG Fixing**: Tracks fixes for known system issues, so you can check whether a feature is working again.


## View and Filter Announcements { #operate-announcements-filter }

Go to the announcement list and filter announcements by type.

1. Log in to the **WMS admin panel** and go to **Announcement**.
2. **Filter by type**: Select the type you want to view at the top of the page.
3. **View details**: Click the **Announcement Title** you want to read. The full announcement and its attachments expand.


## Announcement Alerts { #specs-announcements-reminders }

To make sure you do not miss important news, the system alerts you proactively:

- **Full-screen pop-up**: When a new major announcement is published, it pops up automatically after you log in to the admin panel. It stays on screen for **5 seconds** so you see it right away.
