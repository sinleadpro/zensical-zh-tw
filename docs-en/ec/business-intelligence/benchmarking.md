## About Benchmarking <small>Benchmarking</small> { #intro-benchmarking }

Benchmarking uses **AI machine learning** to analyze data such as a merchant's product categories and revenue performance, select a suitable "peer group" from the system, and calculate industry benchmark ranges. This shows you how each of your store's metrics compares with your industry, so you can quickly spot weak areas to improve.

## Eligibility and Limitations { #prerequisites-benchmarking-applicability }

- [x] **Plan:** Available only to **Enterprise** customers.
- [x] **Supported product categories:** Currently in beta, mainly supporting merchants in these four categories:
    - Food, Beverages & Tobacco
    - Health & Beauty
    - Apparel & Accessories
    - Home & Garden
- [x] **Recognized order definition:** Data counts only orders that meet both conditions: "order status is not canceled" and "no return needed or return rejected."

## Four Key Benchmark Metrics { #reference-benchmarking-key-metrics }

The system provides benchmark ranges for four core e-commerce metrics:

1. **Traffic:** The number of visits to your site (similar to sessions in Google Analytics).
2. **Conversion Rate:** Calculated as "total orders ÷ total traffic."
3. **Average Order Value (AOV):** Calculated as "total revenue ÷ total orders."
4. **Repurchase Rate:** The share of all ordering customers who have placed 2 or more orders within the specified period.

![Four benchmarking metrics](../../assets/images/ec-bi-benchmarking-four-metrics.zh-tw.en.png){ title="Four Benchmark Metrics" }

## Use Benchmark Data to Grow Sales { #overview-benchmarking-performance }

Refer to the e-commerce formula: **GMV (total revenue) = traffic × conversion rate × average order value × repurchase rate**.

- **Set optimization priorities:** When a metric is **below the market benchmark range**, improving it usually pays off more, so make it the top priority in your optimization plan.
- **Campaign period analysis:** Set a custom period (such as Lunar New Year or an anniversary sale) and compare it with the same period last year or the previous period to measure your marketing campaign results.

## Steps { #operate-benchmarking }

1. **Open the page:** Sign in to the admin and click **"Charts" > "Summary Chart"**.
2. **View the trend chart:** In Chart Overview, you see the current period's data. If your store is in one of the product categories above, the system also shows benchmark ranges on the metric cards automatically.
3. **Learning resources:** CYBERBIZ regularly offers online courses and tutorial videos on each metric (for example, SEO to increase traffic or add-on purchases to increase average order value) for brands to use.
