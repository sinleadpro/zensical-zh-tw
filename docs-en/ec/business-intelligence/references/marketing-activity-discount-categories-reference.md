# Discount Types Reference

"Discount Type Analysis" and "Discount Campaign Rankings" in "Shop Campaign Analysis" are broken down by discount type. The system currently offers these 5 discount types:

| Discount Type | Description | Activation Requirement |
| :-- | :-- | :-- |
| Order Add-On | At checkout, when the whole order meets the set conditions, the customer can buy specified products at an add-on price. | Requires the "Order Add-On" marketing feature to be turned on |
| Product Add-On | When buying a specified product, the customer can buy a matching product at an add-on price. | Requires the "Product Add-On" marketing feature to be turned on |
| Bundle Discounts | A discount is given when a combination of products meets the set conditions. | Requires the "Bundle Discounts" marketing feature to be turned on |
| Coupons | The customer gets a discount by entering a promo code at checkout. |  |
| Buy X get Y Discounts | The customer gets a discount by choosing a set number of items from specified products. |  |

!!! note "Note"
    * "Order Add-On," "Product Add-On," and "Bundle Discounts" appear in the drop-down menu only after you turn on the matching marketing feature. They are hidden if the feature is off.
    * "Coupons" (promo code discounts) and "Buy X get Y Discounts" are built-in features and are visible on every plan that can use this page.
