# Chart Overview Metrics Reference

### Chart Overview Metrics { #reference-bi-overview-metrics }

| Metric | What It Means for Merchants | Calculation | Available in Trend Chart | Benchmark Reference Range |
| :-- | :-- | :-- | :--: | :--: |
| Traffic | Traffic from customers visiting your site, similar to sessions in Google Analytics | — | ✓ | ✓ |
| Conversion Rate | The share of visits that result in an order on average | Total orders ÷ total traffic | ✓ | ✓ |
| Orders | Number of recognized orders in the period | Sum of recognized orders | ✓ | — |
| Average Order Value | Average transaction amount per order | Total revenue ÷ total orders | ✓ | ✓ |
| Revenue | Total amount of recognized orders in the period | Sum of recognized order amounts | ✓ | — |
| Registered Members | Number of members who registered in the period | Sum of new registrations in the period | ✓ | — |
| Repurchase Rate | The share of returning customers among customers who ordered in the specified period | Customers with 2 or more orders ever ÷ customers who ordered in the specified period × 100% | — | ✓ |

!!! note "Note"
    * All metrics are calculated from "recognized orders" (orders that are not canceled and whose return status is no return needed or return rejected).
    * Metric cards show totals, named "Total Traffic," "Total Orders," "Total Revenue," and so on.
    * "Repurchase Rate" appears only on metric cards, not in the trend chart's metric list.
    * Metrics marked ✓ in the "Benchmark Reference Range" column are available only on the Enterprise plan, and only for merchants in supported industries.
