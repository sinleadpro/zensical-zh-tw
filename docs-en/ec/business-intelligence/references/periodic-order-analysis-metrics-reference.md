# Subscription Order Analysis Metric Definitions Reference

This page explains the metrics on each data card and chart on the "Subscription Order Analysis" page.

### Subscription Data Cards { #reference-periodic-orders-cards }

| Metric | What It Means | Scope |
| :-- | :-- | :-- |
| Total Subscription Orders | Cumulative number of subscription orders (subscriptions) created in your store | All-time cumulative |
| Total Cycles Completed | Total number of delivery cycles actually generated by all subscription orders | All-time cumulative |
| Total Subscription Order Value | Total sales amount of orders actually placed from subscription orders | All-time cumulative |

!!! note "Note"
    * All three data cards are **all-time cumulative** and are not affected by the chart date ranges.
    * A "subscription order" is one subscription created by a customer. A "cycle" is each delivery that subscription actually generates.
    * "Total Subscription Order Value" includes only the amounts of cycles whose orders have actually been placed. Cycles without a placed order are not included.

---

### Subscription Charts { #reference-periodic-orders-charts }

| Chart | Type | What It Shows | What It Counts |
| :-- | :-- | :-- | :-- |
| Subscription Order Duration Ratio Chart | Pie chart | Percentage of subscription orders at each "number of cycles completed" | All subscription orders |
| Subscription Order Duration Chart | Bar chart | Number of subscription orders at each "number of cycles completed" (x-axis: duration; y-axis: count) | All subscription orders |
| Cancellation at Cycle N Ratio Chart | Pie chart | For canceled subscription orders, the share canceled at each cycle | Canceled subscription orders |
| Cancellation at Cycle N Count Chart | Bar chart | For canceled subscription orders, the number canceled at each cycle (x-axis: cycle; y-axis: count) | Canceled subscription orders |
| Subscription Order Cancellation Ratio Chart | Pie chart | Share of "canceled / not canceled" among all subscription orders | All subscription orders (subscription level) |
| Single-Cycle Cancellation Ratio Chart | Pie chart | Share of "canceled / not canceled" by individual delivery cycle | All delivery cycles (cycle level) |

!!! note "Note"
    * Each of the six charts uses its own date range and counts by subscription order creation time. When the page first loads, it shows about the last 6 months by default.
    * "Duration" is the number of delivery cycles a subscription order has actually completed.
    * The "Cancellation at Cycle N" charts count only **canceled** subscription orders, so you can see at which cycle customers tend to drop off.
    * "Subscription Order Cancellation Ratio" counts by whole subscription, while "Single-Cycle Cancellation Ratio" counts by each delivery. Because they count at different levels, the numbers are usually different.
