# Benchmark Reference Range Status Reference

### Benchmark Reference Range Statuses { #reference-chart-overview-benchmark-status }

| Status | What It Means | Recommended Action |
| :-- | :-- | :-- |
| Better than the benchmark | This metric is above the industry benchmark range | Keep your current approach and apply what works to other metrics |
| In line with the benchmark | This metric is within the industry benchmark range | Performance is stable; optimize further when you have capacity |
| Below the benchmark | This metric is below the industry benchmark range | Improvements here pay off more; make this a priority |

!!! note "Note"
    * Benchmark reference ranges and status labels are available only on the **Enterprise** plan, and only for merchants in supported industries.
    * "Below the benchmark" is shown in red to signal that the metric has more room to grow.
    * Benchmarks come from "statistics on merchants in similar categories with comparable performance." They are reference ranges compiled across the industry, not figures from a single store.
