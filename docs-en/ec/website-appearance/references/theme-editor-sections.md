This reference summarizes the blocks you can add in a drag-and-drop theme and what they are for. Docs such as "Drag-and-Drop Theme Site Settings" link to it.

## Common Blocks You Can Add { #reference-theme-editor-sections }

| Block type | Available on | Description | Requirements |
| :-- | :-- | :-- | :-- |
| Carousel | Homepage, custom pages | Rotates multiple images. Often used for a page's key visual and campaign exposure | — |
| Banner ad | Homepage, custom pages | A single large banner that can include a button to drive sales | — |
| Product categories | Homepage, custom pages | A product showcase that displays the products in a category | — |
| Video settings | Homepage, custom pages, one-page pages | Embeds a YouTube video | — |
| Tabs | Homepage | Shows multiple blog groups that shoppers switch between with tabs | — |
| Custom layout design | Homepage, custom pages, one-page pages | Mixes several elements in one row (images, videos, scheduled carousels, custom HTML, products) | — |
| Image and text | Homepage, custom pages, one-page pages | Image and text side by side, suited to brand or feature introductions | — |
| Custom HTML | Homepage, custom pages, one-page pages | Paste custom HTML/CSS, or embed third-party services (such as an Instagram feed) | — |
| Apps | Homepage | Shows content provided by installed apps | — |
| Text editor | Homepage, custom pages, one-page pages | Plain body text with adjustable font size | — |
| Featured product | Homepage | Highlights a single key product | — |
| Collapsible content | Homepage, custom pages, one-page pages | Content that expands and collapses when clicked, suited to FAQs and shopping notes | — |

!!! note "Note"
    * The table lists common blocks. **The blocks you can actually add, and their names, vary with the drag-and-drop theme you installed and your plan**. Go by the "Add Block" list in the editor.
    * For each block's detailed fields (image size, carousel interval, number of product columns, margins, and so on), see [Page Settings](../theme-and-layout/setup-theme-page-settings.md#overview-page-settings){ title="Page Settings Guide" }.
    * **Product pages have fixed blocks** (product information, product description, related products, and product reviews, which require the feature to be turned on). They do not appear in the "Add Block" list. For how to set them up, see [Page Settings](../theme-and-layout/setup-theme-page-settings.md#operate-page-settings-product){ title="Page Settings Guide" }.
    * **Pop-up ads, the header menu, and the footer are site-wide settings**, not blocks you can add. For pop-up ad settings, see [Global Settings](../theme-and-layout/setup-global-theme-settings.md#operate-global-settings-popup){ title="Global Settings" }.
    * Some blocks contain several smaller blocks (such as each image in a carousel or each element in a custom layout design). Click into them to set each one.
