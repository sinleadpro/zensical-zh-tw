# Theme Types Reference

| Type | Description | Best For |
| :-- | :-- | :-- |
| Drag-and-drop theme | No coding required. Click and drag with your mouse to rearrange sections and layouts. Supports the latest storefront features. Theme cards carry a "Drag-and-Drop Settings" label. | Merchants who want to adjust layouts freely without writing code |
| Default theme | Opens up HTML, CSS, and JS for in-depth visual customization. The system no longer updates this type of theme. | Merchants with a technical background who need a high degree of customization |
| Multilingual theme | A theme that supports switching between languages on the storefront. Theme cards carry a "Multilingual Theme" label. | Merchants running multilingual online stores (such as a North America site or a Japan site) |

!!! note "Note"
    * The theme library shows the "New Drag-and-Drop Themes" category by default. When you switch to the "Default Themes" category, a reminder says that these themes are no longer updated.
    * For multilingual stores, the theme library adjusts automatically to the store's region and shows only the themes that apply.
