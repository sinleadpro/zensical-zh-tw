This reference summarizes what you can edit on each page of a drag-and-drop theme. Docs such as "Drag-and-Drop Theme Site Settings" link to it.

## Editing Options by Page { #reference-theme-editor-pages }

Pages in a drag-and-drop theme fall into three groups based on how much you can edit: **add and remove blocks freely**, **reorder or edit existing blocks only**, and **fixed layout**. For the actual settings on each page, see [Block Types You Can Add](theme-editor-sections.md).

| Page | Editing options | Included or available blocks |
| :-- | :-- | :-- |
| Homepage | Add, reorder, and delete blocks freely | See [Block Types You Can Add](theme-editor-sections.md) |
| Custom page | Add, reorder, and delete blocks freely | See [Block Types You Can Add](theme-editor-sections.md) |
| One-page page | Add, reorder, and delete blocks freely | See [Block Types You Can Add](theme-editor-sections.md) |
| Product page | Reorder and edit existing blocks (cannot add blocks) | Product information, product description, recommended products, product reviews |
| Product collection page | Fixed layout that follows the overall style | — |
| Multi-level product categories | Fixed layout that follows the overall style | — |
| Blog page | Fixed layout that follows the overall style | — |
| Blog post page | Fixed layout that follows the overall style | — |
| Cart page | Fixed layout that follows the overall style | — |
| Quick delivery page | Fixed layout that follows the overall style | — |
| Customer service page | Fixed layout that follows the overall style | — |
| Search page | Fixed layout that follows the overall style | — |
| 404 page | Fixed layout that follows the overall style | — |

!!! note "Note"
    * **Add, reorder, and delete blocks freely**: Add blocks from the "Add Block" list, drag to reorder them, and remove blocks.
    * **Reorder or edit existing blocks only**: You cannot add new blocks, but you can change the content and order of existing blocks (for example, product information, product description, recommended products, and product reviews on the product page).
    * **Fixed layout**: The system sets the page structure, so you cannot adjust it block by block. The theme's overall style (colors, fonts, and so on) still applies.
    * The pages you can edit vary slightly depending on the drag-and-drop theme you installed. The page drop-down menu at the top of the editor shows what is available.
