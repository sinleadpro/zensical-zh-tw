## Custom Page Blocks Reference { #reference-custom-pages-blocks }

The blocks below apply to **new (drag-and-drop) custom pages**. Add them in the theme editor by clicking **"Add Block"**. You can add each block more than once and rearrange them freely.

| Block | Description | Availability |
| :-- | :-- | :-- |
| Carousel | A banner of multiple images that rotate automatically. Often used for a page's key visual and campaign exposure. You can set how many images show per rotation. | Built in |
| Banner ad | A placement for one or more banner images. Each image can link to a URL, which suits campaigns or featured products. | Built in |
| Product categories | Shows product category entry points as image-and-text blocks that lead customers to the matching category pages. | Built in |
| Custom layout design | Freely adjust the screen share and order of multiple images to build a custom image-and-text layout. | Built in |
| Video settings | Embeds a video and lets you set behavior such as autoplay (videos are muted automatically when autoplay is on). | Built in |
| Image and text | An introduction block that pairs an image with text, suited to brand stories, service highlights, and similar content. | Built in |
| Custom HTML | Paste in your own HTML or an external embed code, such as a Google Form, interactive content, or third-party code. | Built in |
| Text editor | Write paragraphs in the text editor. Suited to long text such as terms of service, privacy policies, and help articles. | Built in |
| Collapsible content | Content that expands only when clicked. Often used for FAQs, shopping notes, and Q&A. | Built in |

!!! note "Note"
    * The block list changes with the features your store has turned on. The "Add Block" panel in the theme editor shows what is actually available.
