# Apply for an Apple Developer Account
Enroll in the Apple Developer Program, get a D-U-N-S Number, and authorize CYBERBIZ in App Store Connect so your iOS app can be published.
{ .subtitle }

[:lucide-grid-2x2-plus:{ title="Applicable Add-ons" }](../../resources/conventions.md#適用擴充) | CYBERBIZ APP
{ .doc-badge }

## Before You Start { #prerequisites-apple-account }

- To publish your CYBERBIZ App on the App Store, you must first apply for an Apple developer account. Follow the guide below to complete the application.
- Apple's developer account service is officially called the Apple Developer Program. For more information, see the [Apple Developer website](https://developer.apple.com/programs/).

## Preparation Checklist { #prerequisites-apple-preparation }


### Basic Information { #prerequisites-apple-data }

- [x] Company details (name, address, and phone number)
- [x] A contact person who can answer phone calls (for the D-U-N-S Number and Apple phone verification)
- [x] A credit card (to pay the developer fee)

### Apple Developer Program Requirements { #prerequisites-apple-conditions }

- [x] An Apple ID
- [x] A D-U-N-S Number (if you don't have one yet, you can request it during the Apple developer account application)
- [x] A legal entity (trade names and branch offices are not accepted)
- [x] The authority to sign legal agreements
- [x] A company website with a valid SSL certificate (https)
- [x] An email address on your company domain (for example, contact@yourcompany.com)


## Apple Developer Program Application Process { #operate-apple-application }

### Step 1: Prepare an Apple ID { #operate-apple-id }

1.  Use an existing Apple ID, or go to [Apple Account sign-up](https://account.apple.com/account) to create a new one.
    *   Each Apple ID can enroll in only one Apple Developer Program account. If you have already used your Apple ID to enroll another organization, register a new Apple ID.
2.  Complete email and mobile number verification.

### Step 2: Request a D-U-N-S Number (Skip If You Already Have One) { #operate-apple-duns }

1.  Go to the [Apple D-U-N-S lookup page](https://developer.apple.com/enroll/duns-lookup/).
2.  Sign in with your Apple ID and enter your company information.
    *   Use an email address on your company domain.
    *   Provide the details of a contact person who can answer phone calls.
    *   If the system shows a matching company record, clear the checkbox and click **Back**, then click **Submit your information**.
    *   If you have never registered for a D-U-N-S Number, select the terms checkbox and click **Submit**.
3.  You will receive a notice when the registration is complete.
4.  After you submit, wait for the D&B phone verification.

### Step 3: Apply for an Apple Developer Account { #operate-apple-developer }

1.  Go to the [Apple Enrollment page](https://developer.apple.com/programs/enroll/).
2.  Sign in with your Apple ID.
3.  Select **Company / Organization** and enter your company name and D-U-N-S Number.
4.  Submit the application and wait for Apple's phone review.
5.  After approval, pay the annual fee (see Apple's program policy for the fee).
