This reference maps admin permissions to admin panel menus, so you can quickly see which admin panel features each permission gives access to when you add or set up admin accounts.
{ .subtitle }


!!! info "Scope"
    This table lists every feature. The menus you actually see in the admin panel depend on your **contract plan** and **account permission level**.


| Feature category | Matching admin panel sidebar menus |
| ---------- | ---------- |
| Overview | Overview |
| Customers | All Customers / VIP Settings / Import New Member Data |
| Orders | All Orders / Subscription Orders / E-Voucher Orders / Shop.com Orders / EZCAT Cod Orders / EZCAT CVS Orders / EZCAT Cold CVS Orders / Pelican Cod Orders / Convenience Store Orders / Hi-Life C2C Orders / EZCAT Return Orders / EZCAT CVS Return Orders / EZCAT Cold CVS Return Orders / Pelican Return Orders / Convenience Store Return Orders / Hi-Life C2C Return Orders / Issue Management / Message Sort by Member / Message Sort by Orders |
| Promotions | Marketing Campaign Analysis / store-wide discount - Bonus & coupon |
| Products | Products (only products added by this account) / All Products / Product Tag Management / Import Products from Excel / Inventory List |
| View all products | All Products / Inventory List |
| Product groups | Flash Sale for Single Product / E-Voucher Buy X Get Y Discount / Bundle Discounts / Free Gifts with Purchase / PWP-By Order / PWP-By Product / limited-time first-purchase gift / Issue coupon for Selected Product / Issue Bonus Points for Selected Product / Bonus for Specific Payment / Bonus for Specific Shipping / Bonus Mall / Product Multi Level Filter Full Discount / Product Not Applicable to Selected Promotion / Limited Purchase Setting / Collection Sorting in Storefront |
| Cart & payment | Payment Method Thresholds / Home Delivery Shipping Fees |
| Appearance | Theme Setting |
| Blog & pages | Blog Management (Articles/Categories) / Blog Sorting / Article Tag Management / Customized Pages Management |
| Link lists | Menu Setting |
| Settings | Message Categories / LINE OA Message Templates / LINE Tag Settings / Checkout Page & Logistics / Email Notification Template / Shopping Notice / General / URL Redirection / Domain / Invoices |
| Charts | Summary Chart / Revenue Analysis / Orders Analysis / Member Insights / Product Analysis / Product Subscription Analysis |
| Customer feedback | Member Feedbacks |
| SMS | Send SMS Messages / SMS Sending History |
| EDM | Send Marketing Emails / Email Marketing History |
| Refunds | Refund feature |
| Shipping label printing | EZCAT Shipping Label / EZCAT Convenience Store Shipping Label / Pelican Express Shipping Label / SF Express Shipping Label |
| Event page settings | Event Page / Subscription Campaign Event Page |
| Profit sharing | With Referrers / With Registrants / Referral Reports |
| Store settings | Store Pickup Settings |
| LINE AT | LINE OA Settings / LINE OA Marketing Campaigns |
| Interactive games | Interactive Games |
| Comment system | Product Reviews Pending Approval |
| Scheduled banner settings | Scheduled Slidable Banner |
| Account management | Reconciliation Center |
| Member-exclusive prices | Whether you can import members with exclusive prices |
| APP MARKET | My Apps / App Store |
| Customer export | Export Customer Data |
| Order export | Order Data Export |
| Third-party integrations | Facebook / Google / Shop.com / LINE Login / LINE Shopping / LINE Tag Settings / Yahoo |
