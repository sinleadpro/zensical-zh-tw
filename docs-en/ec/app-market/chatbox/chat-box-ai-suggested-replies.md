# CHAT BOX AI Suggested Replies
An AI assistant learns your brand policies and product information automatically and suggests fast, accurate replies to customer inquiries.
{ .subtitle }

[:lucide-tag:{ title="Applicable Plans" }](../../resources/conventions#適用方案) | All PLUS / Enterprise<br>
[:lucide-grid-2x2-plus:{ title="Applicable Add-ons" }](../../resources/conventions#適用擴充) | CYBERBIZ CHAT BOX
{ .doc-badge }


!!! tip "Use Cases"
    - **Answer Common Questions Faster**: Upload your return and exchange policy and shipping details to the knowledge base, and AI drafts replies for you so you do not have to retype the same content.
    - **Recommend Products Accurately**: After AI learns your product guides, it can give accurate specifications or buying advice based on what the customer needs.
    - **Keep Service Quality Consistent**: Even new customer service staff can send replies that match your brand voice and contain correct information.


## Before You Start { #prerequisites-chat-ai }

- **Better Data, Better Replies**: The more detailed your uploaded documents are (such as FAQs or internal SOPs), the more accurate the AI's replies.
- **Privacy and Security**: When you turn off the feature or delete a file, the system immediately removes that data from the AI model to keep your business information secure.
- **Human Review**: AI replies are for reference only. Always review and adjust them before sending.


## Set up the AI Assistant { #operate-chat-ai }

Go to **APP MARKET > CHAT BOX** and click **AI Center** to set it up.

### 1. Turn on the Feature { #operate-chat-ai-1-enable }

Turn on "Enable AI Suggested Replies". After you turn it on, an AI icon appears above the chat box whenever a new message arrives.

![](https://www.cyberbiz.io/support/wp-content/uploads/EC-後台-APPMARKET-CHATBOX-AI助手01.png){ .screenshot }

### 2. Build the Customer Service Knowledge Base { #operate-chat-ai-2-create-data }

Click **Upload File** to add your brand policies or product manuals to the AI knowledge base.

- **Supported Formats and Limits**:
    - **TXT**: Up to 1 MB per file.
    - **PDF**: Up to 5 MB per file.
- **File Limit**: Up to 20 files.

![](https://www.cyberbiz.io/support/wp-content/uploads/EC-後台-APPMARKET-CHATBOX-AI助手02.png){ .screenshot }

### 3. Track File Processing Status { #operate-chat-ai-3-file-status }

After you upload a file, AI needs time to read it and add it to the model. Check the file status:

- **Processing**: AI is learning the content. You cannot click the file yet.
- **Processed**: The file name turns into a blue link, which means it was added successfully. Click it to view the content.
- **Processing Error**: If the file is damaged or in the wrong format, delete it and upload it again.

![](https://www.cyberbiz.io/support/wp-content/uploads/EC-後台-APPMARKET-CHATBOX-AI助手05.png){ .screenshot }



## Reply to Customers with the AI Assistant { #intro-chat-ai }

When a customer sends an inquiry, use the AI assistant as follows:

1. **Trigger an AI Suggestion**: Click the AI icon in the chat box. AI reads the conversation and identifies the main question.
2. **Generate a Draft**: The system instantly creates a draft reply.
3. **Verify the Information**: If the suggestion is based on a specific source (such as a storefront product page), click the icon to open it and check.
4. **Edit the Reply**: Click the edit icon to revise the AI's text directly.
5. **Send the Message**: After you confirm the content, click the send button to reply.

![](https://www.cyberbiz.io/support/wp-content/uploads/EC-後台-APPMARKET-CHATBOX-AI助手04.png){ .screenshot }
