This table lists the product sort orders available in Conditionalized Collections. The sort order decides the order in which matching products appear on the storefront category page.

## Product Sort Order Reference { #smart-collections-sort-orders }

| Sort Order | Product Order on the Storefront |
| :-- | :-- |
| Title Ascending: A-Z | Sorted by product name from A to Z (smallest to largest) |
| Title Descending: Z-A | Sorted by product name from Z to A (largest to smallest) |
| Created Date: Newest-Oldest | The most recently created products come first |
| Created Date: Oldest-Newest | The earliest created products come first |
| Price: Highest-Lowest | Sorted by price from high to low |
| Price: Lowest-Highest | Sorted by price from low to high |
| Best Sellers | Sorted by sales performance from best-selling to least popular |
| Manual Sorting | You drag products to set their order yourself |

!!! note "Notes"
    * Only after you select "Manual Sorting" can you drag to reorder the matching product list. All other sort orders are arranged automatically by the system and cannot be dragged manually.
    * Sorting only affects the order in which products appear on the storefront category page. It does not affect whether a product is included in the collection (inclusion is decided by the filter conditions).
