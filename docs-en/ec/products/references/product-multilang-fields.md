This table lists the product fields that **can be filled in separately for each language** in a multi-language store, for reference in guides on adding products and building multi-language content. Fields not listed below (such as price, variants, SKU, inventory, and images) are shared by all languages and only need to be set once.

## Translatable Fields { #reference-product-multilang-fields }

| Tab | Translatable Field | Description |
| :-- | :-- | :-- |
| Product Information | Product Name | The main name of the product shown on the storefront |
| Product Information | Product Slogan | A short feature or promotional phrase near the product name |
| Product Information | Product Brief | A short description of the product |
| Product Information | Product Options | The name of an option (such as "Color" or "Size") |
| Product Information | Option Values | The values under an option (such as "Red" or "Blue") |
| Product Description | Product Description | The main introduction to the product |
| Product Description | Specification Description | Details such as specifications, materials, and sizes |
| Product Description | Shipping Method | Information about shipping and delivery |

!!! note "Notes"
    * After you switch languages, a tag next to these fields shows the language you are editing, as a reminder of which language's content you are working on.
    * Save before you switch languages. Otherwise, the system shows the prompt "Please save your changes before editing other languages."
    * Some languages are AI-translated. You can check and correct the wording manually.
