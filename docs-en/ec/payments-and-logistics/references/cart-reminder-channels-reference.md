# Abandoned Cart Reminder Channels Reference

This reference summarizes the notification channels and activation requirements available for automatic abandoned cart reminders. It is intended for reference in checkout and payment and logistics settings.

## Notification Channels and Activation Requirements { #cart-reminder-channels }

| Channel | Description | Activation Requirement |
| :-- | :-- | :-- |
| Email Reminder | Sends email reminders to customers who have items left in their cart | Included in most paid plans |
| SMS Reminder | Sends SMS reminders to customers. Each message consumes CYBER Coins based on its length. | Included in most paid plans |
| LINE OA Reminder | Sends push reminders through the LINE Official Account | PLUS plan or higher, or Enterprise plan |

!!! note "Note"
    * Up to three reminders can be set, and the maximum send window for each reminder is 14 days.
    * SMS and LINE OA reminders consume CYBER Coins. If the balance is insufficient, sending fails, so check the balance in advance.
    * Notification content for each channel can be adjusted on the corresponding pages: "Email & Reminders", "SMS Settings", or "LINE@ Settings".
    * Which channels appear depends on the features activated for the store.
