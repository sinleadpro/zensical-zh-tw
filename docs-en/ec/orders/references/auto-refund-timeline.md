The maximum number of days each payment provider allows for automatic card refunds. After that, you must use a manual refund.

| Payment Method | Automatic Refund Limit | After the Limit |
| :-- | :-- | :-- |
| LINE Pay | 60 days | Use manual refund |
| Pay2Go (ECPay) credit card | 90 days | Use manual refund |
| GMO credit card | 90 days | Use manual refund |
| CYBERBIZ Pay (Taiwan cards) | 179 days | Use manual refund |
| PayPal | 180 days | Use manual refund |
| JKOPAY | 180 days | Use manual refund |

!!! note "Notes"
    * Days are counted from the order payment date.
    * Payment methods not listed (such as cash on delivery and ATM transfer) have no automatic card refund, so you must refund them manually.
