## Facebook Domain Verification Guide { #operate-fbe-domain }

**Facebook Domain Verification** is designed to let you claim domain ownership in Business Manager. This lets you control link editing permissions, improve ad performance, and prevent others from misusing your website.

## Prerequisites and Limitations { #prerequisites-fbe-domain }

- [x] First, [enable Facebook Business Extension and related asset connections](setup-fbe-authorization.md){ title=" set up FBE account authorization and asset connections" }.

## Choose a Domain Verification Method { #operate-fbe-domain-verification }

Domain verification has two main methods: [DNS verification](#operate-fbe-domain-steps-dns-verification-use) and [meta tag verification](#operate-fbe-domain-steps-verification-meta-tag).

!!! info "We recommend using DNS verification first. Meta tag verification requires editing backend code. If you make a mistake, the platform provider is not responsible for changes to backend program code. For more verification information, see the [official documentation :lucide-external-link:](https://zh-tw.facebook.com/business/help/321167023127050)."

## Steps { #operate-fbe-domain-steps }

### DNS Verification <small>Recommended</small> { #operate-fbe-domain-steps-dns-verification-use }

1.  **Go to Business Manager**: Log in to [Business Manager :lucide-external-link:](https://business.facebook.com/latest/settings), click "Settings" > "Brand Safety and Suitability" > "Domains," and add your primary domain name.

    ![Business Manager-Add Domain](../../../../assets/images/ec-第三方整合-meta企業管理平台-新增網域.en.gif)

2.  **Copy the TXT record**: Select "DNS verification" and copy the TXT record code generated by the system.

    ![Business Manager-DNS TXT Record](../../../../assets/images/ec-第三方整合-meta企業管理平台-dnd-txt紀錄.en.png)

3.  **Go to your domain registrar's settings**:

    === ":simple-gandi: GANDI"

        1. First, complete [CNAME and redirect setup](../../../website-management/domain-management.md#operate-domain-mgmt-dns) in { title="Domain Management" }
        2. Log in to the [Gandi Dashboard :lucide-external-link:](https://admin.gandi.net/), go to "Zone File Records," add a TXT record, enter `@` in the name field, and paste the copied TXT code in the value field.

        ![](../../../../assets/images/ec-第三方整合-meta企業管理平台-dnd-txt紀錄新增-gandi.en.png)

        !!! info "For more Gandi DNS record instructions, see the [official documentation :lucide-external-link:](https://docs.gandi.net/zh-hant/domain_names/common_operations/dns_records.html)."

    === ":simple-godaddy: GoDaddy"

        **GoDaddy**: After you complete the CNAME and redirect setup, go to DNS management and add a TXT record. For Host, enter `@`, and set the TTL to 1 hour.

    === "HiNet"

        1. Complete [CNAME and redirect](../../../website-management/domain-management.md#operate-domain-mgmt-dns) in { title="Domain Management" }.
        2. Log in to the [HiNet website :lucide-external-link:](https://domain.hinet.net/#/), go to "My Domains" > "Redirect Service" > "Set Up Redirect," and copy the A record IP.

            ![HiNet-Copy A Record IP](../../../../assets/images/ec-第三方整合-meta企業管理平台-更新dns-hinet-複製a紀錄ip.en.png)

        3. Add an A record and a TXT record:
            *   **A record**: Leave "Host name/alias" blank, set "Record type" to `A`, and enter the IP address you copied in step 2.
            *   **TXT record**: Leave "Host name/alias" blank, set "Record type" to `TXT`, and paste the TXT code copied from Business Manager into "IP/Host name" (**Add the `""` symbol before and after the code, and keep the code in lowercase**).

            ![HiNet-Add DNS TXT Record](../../../../assets/images/ec-第三方整合-meta企業管理平台-dnd-txt紀錄新增-hinet.en.png)
    === "Far EasTone (Formerly Asia Pacific Telecom)"

        !!! warning "The original "Asia Pacific e-Manager" DNS backend has been shut down"
            After Asia Pacific Telecom merged with Far EasTone, the original "Asia Pacific e-Manager" DNS management backend was **officially shut down in 2025**. Log in to the **Far EasTone Seednet RS Domain Registration Center** instead to complete domain verification.

        Follow these steps to complete FB domain verification on the Seednet platform:

        1. **Log in to the platform**: Go to the [Seednet RS Domain Registration Center](https://seed.net.tw).
        2. **Go to settings**: Click "My Domain Management" > click the domain > "DNS Hosting Settings."
        3. **Add a record**:
            *   **Type**: Select `TXT`.
            *   **Host name**: Enter `@`.
            *   **Record value**: Paste the `facebook-domain-verification=...` string provided by FB.

4.  **Complete verification**: After setup, wait **2~3 days**, then return to Business Manager and confirm the status has changed to "Verified."

    ![Business Manager-Verification Successful](../../../../assets/images/ec-第三方整合-meta商家資產管理平台-驗證成功.en.png)

### Meta Tag Verification <small>Meta-tag</small> { #operate-fbe-domain-steps-verification-meta-tag }

1.  **Get the code**: In Business Manager, go to the "Domains" page under "Brand Safety and Suitability," click "Meta-tag Verification," and copy the entire code.

    ![Business Manager-Meta-tag Code](../../../../assets/images/ec-第三方整合-meta企業管理平台-中繼標籤紀錄.en.png)

2.  **Embed the code in the CYBERBIZ backend**:
    *   Path: **"Website Appearance"** > **"Theme Management"** > **"Code Editor"** > Click **`theme.liquid`**.
    *   Paste the copied Meta-tag code in front of the **`</head>`** tag in the file content and save.

    ![CYBERBIZ Backend-Embed Meta-tag Code](../../../../assets/images/ec-第三方整合-meta企業管理平台-中繼標籤紀錄-埋代碼至CYB後台.en.png)

!!! warning "Note on Redirect Restrictions"
    Facebook only verifies redirected URLs (for example, `yourname.com` redirects to `www.yourname.com`). Subdomains must have a CNAME pointing to `yourname.cyberbiz.co`.

## FAQ { #faq-fbe-domain }

??? quote "Why do I need to complete domain verification before I can set up events?"

    After you complete domain verification, you can set permissions for **Aggregated Event Measurement**. Merchants must own their domain to fully configure **8 events**.

??? quote "What should I do if I pasted the code but verification failed?"

    If you pasted the code but verification failed, you can troubleshoot as follows:

    1.  Enter your domain in a browser and remove `www` to check whether you can still access the website you created in CYBERBIZ.
    2.  If you cannot connect, the root domain has not been redirected yet. Set up the redirect in your DNS provider's backend.

    Because Facebook only recognizes domains without `www`, if verification fails, see the [Domain Management](../../../website-management/domain-management.md){ title="Domain Management" } guide and set up the redirect in your DNS provider's backend.
