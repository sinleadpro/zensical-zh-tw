## Exclude Internal and Third-Party Traffic Guide { #overview-ga-exclude }

To get accurate data in Google Analytics 4 (GA4), exclude traffic from company staff and visits that redirect to third-party payment and logistics sites during checkout. This step prevents conversion sources from being misattributed and improves the accuracy of traffic analysis.

## Setup Steps { #operate-ga-exclude }

### Go to the GA4 Code Settings Page { #operate-ga-exclude-ga4-settings-page }

Before you configure exclusions, go to the code settings area:

1.  Go to the GA4 dashboard and click Admin in the lower-left corner.
2.  Go to Property Settings > Data Collection and Modification > **Data Streams**, and click the stream linked to your website.
3.  On the stream details page, click **Configure tag settings**.
4.  In the settings section, click **Show all** to see the advanced settings you will need later.

![Tag settings page for internal traffic and referral settings](../../../../assets/images/ec-ga4-代碼設定-內部流量與參照連結-blurred.en.png){ title="Tag settings page for internal traffic and referral settings" .screenshot }

---

### Exclude Internal Traffic <small>Internal Traffic</small> { #operate-ga-exclude-internal-traffic }

Internal traffic refers to browsing activity generated by developers, customer service staff, or marketing staff while working on the website. Excluding this traffic prevents it from skewing visitor analysis.

#### 1. Define Internal Traffic <small>IP Settings</small> { #operate-ga-exclude-flow-ip-settings }

1.  On the tag settings page, click **Define Internal Traffic**, and then click Create.
2.  Set the rule name (for example, Company Office) and enter the **IP address** that represents your internal network. You can add multiple IP addresses at the same time.

![Define internal traffic rule creation](../../../../assets/images/ec-ga4-定義內部流量-建立規則-blurred.en.png){ title="Define internal traffic - create rule" .screenshot }

---

#### 2. Enable Data Filters { #operate-ga-exclude-enable-data }

After you define IP addresses, you must enable the filter for the changes to take effect:

1.  Return to GA4, then go to Admin > Property Settings > Data Collection and Modification > **Data Filters**.
2.  Click the default **Internal Traffic** filter.
3.  Set Filter operation to Exclude, change Filter state to **Active**, and then click Save.
4.  Click Activate filter to complete the setup.

![Activate Internal Traffic filter workflow](../../../../assets/images/ec-ga4-啟用篩選器.en.gif){ title="Activate the Internal Traffic filter" .screenshot }

---

### List Unsupported Referral URLs <small>Exclude Third-Party Sites</small> { #operate-ga-exclude-overview-ga-exclude }

When customers are redirected to third-party payment and logistics pages (such as ECPay, LINE Pay, or convenience store map pages) for payment or store selection, GA4 often treats them as new referral sources. This interrupts the session.

1.  On the tag settings page, click **List Unsupported Referral URLs**.
2.  Add commonly used third-party payment and logistics URLs to the list. **See the common links recommended for exclusion below.**

## Important Reminders { #intro-ga-exclude }

*   **Data delay**: After setup, GA4 may take **24-48 hours** to process data. Related changes do not appear in real time.
*   **Data retention**: Also check the GA4 data retention period. We recommend manually extending it from the default of 2 months to **14 months** to support long-term trend analysis.

## Frequently Asked Questions { #faq-ga-exclude }

??? quote "Why do I need to exclude referral links from third-party payment and logistics providers?"

    When customers are redirected to third-party payment and logistics pages (such as ECPay or LINE Pay) for payment or store selection, GA4 often mistakes them for new referral sources. This interrupts the session and affects the accuracy of conversion attribution.

??? quote "Why doesn't the data change right after I set up the IP filter?"

    Check the following items:

    - [x] Have you changed the filter state to **Active** in Data Filters?
    - [x] GA4 data processing takes about **24-48 hours**, so data changes after setup do not appear in real time.
