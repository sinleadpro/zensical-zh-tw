    <h3 id="b2" style="font-size: 22px; font-weight: bold; color: #222222; margin: 0 0 16px 0; line-height: 1.3;">2. Storefront site search (magnifier) improvements</h3>

    <div style="color: #4B5563; font-size: 18px; line-height: 1.75; margin-bottom: 32px;">
      <p style="margin: 0 0 8px 0;">Shoppers may not remember the full product name—can partial keywords still find what they want more easily?</p>
      <p style="margin: 0 0 8px 0;">This update improves storefront product search with Chinese keyword tokenization and model-number prefix matching, and changes the default sort to relevance so results better match what shoppers mean.</p>
      <p style="margin: 0 0 8px 0;">Examples:</p>
      <p style="margin: 0 0 4px 0;">• Chinese keywords: search Taiwan grilled corn to find [Taiwan] black-bean grilled corn</p>
      <p style="margin: 0 0 4px 0;">• Product model: search CH or CH2026 to find model CH2026GW16T-3</p>
      <p style="margin: 0;">• Search sort: if product A has the keyword in the product name and product B only in the product description, product A ranks higher</p>
    </div>

    <h3 id="b3" style="font-size: 22px; font-weight: bold; color: #222222; margin: 0 0 16px 0; line-height: 1.3;">3. Bot protection for member registration SMS codes</h3>

    <div style="color: #4B5563; font-size: 18px; line-height: 1.75; margin-bottom: 32px;">
      <p style="margin: 0 0 8px 0;">Worried that bots trigger member registration SMS verification and create unexpected SMS fees?</p>
      <p style="margin: 0 0 8px 0;">You can enable Cloudflare Turnstile storefront protection in the admin. After it is on, members must pass verification before an SMS is sent when they click Send verification code on the registration page, lowering the risk of malicious SMS triggers.</p>
      <p style="margin: 0;">Bot protection for Member feedback and suggestions is also managed in the same place.</p>
    </div>
