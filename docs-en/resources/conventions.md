This section explains a few conventions used in these docs.

## Symbols

These docs use a few symbols for clarity. Before you continue, make sure you know the conventions below:

### :Lucide-Layers: Applicable Products { #conventions-products }

Marks content that applies to CYBERBIZ product lines such as EC, POS, and WMS.

### :Lucide-Tag: Applicable Plans { #conventions-plans }

Marks content that applies only to merchants on specific plans.

### :Lucide-Bolt: Applicable Features { #conventions-features }

Marks content that applies only when a specific admin feature is enabled (for example, multilingual).

### :Lucide-Layout-Dashboard: Applicable Themes { #conventions-themes }

Marks content that applies only to specific storefront themes (for example, drag-and-drop or default themes).

### :Lucide-Grid-2X2-Plus: Applicable Add-Ons { #conventions-extensions }

Marks content that applies to specific CYBERBIZ add-ons.

### :Lucide-Puzzle: Standard / Optional { #conventions-plan-options }

Marks whether the content is a standard or optional module on PLUS plans. Optional modules use an 11-choose-2 model; Enterprise usually includes them by default.
