**Feature overview:**  

* Offer the emerging buy-now-pay-later payment method to make checkout easier for shoppers and grow revenue.
* Shoppers enter a mobile number, complete verification, and can use this payment method. *For payment or other issues, shoppers should contact AFTEE directly. See the [AFTEE official website](https://aftee.tw/).  

**Contents:**

* Apply for AFTEE buy now pay later
* Checkout steps
* Other notes
Notes:  

* Finish the AFTEE application first. After AFTEE approves your company, the system emails your store admins. When you receive the email, return to this page and enable the feature.
* For AFTEE transaction fees, see Admin center / Reconciliation / Payment fees in the admin. Fees exclude VAT; statements add 5% tax.
Apply for AFTEE buy now pay later 1. Enable AFTEE in the admin  
**Admin path:** Payment settings → CYBERBIZ PAYMENTS → AFTEE  

[![AFTEE1](https://www.cyberbiz.io/support/wp-content/uploads/AFTEE先享後付金流說明01.png)](https://www.cyberbiz.io/support/wp-content/uploads/AFTEE先享後付金流說明01.png) 2. Fill in the application  
Click Apply, then complete the AFTEE Application dialog. AFTEE uses this information for review, so enter it carefully.  
[![AFTEE](https://www.cyberbiz.io/support/wp-content/uploads/AFTEE先享後付金流說明02.png)](https://www.cyberbiz.io/support/wp-content/uploads/AFTEE先享後付金流說明02.png)  
After AFTEE successfully receives the application data from the API, access is enabled right away.  
Sample approval email.  
[![AFTEE](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明03.png)](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明03.png) 3. Enable Buy now pay later (convenience store / ATM).  
[![AFTEE](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明04.png)](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明04.png) 4. Sample storefront checkout page.  
[![AFTEE](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明05.png)](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明05.png)

Checkout steps 1. On the checkout page, choose a buy-now-pay-later method and continue to checkout.  
[![AFTEE](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明06.png)](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明06.png) 2. Click the Pay with buy now pay later button  
[![AFTEE](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明06.png)](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明06.png) 3. Enter the mobile number registered with AFTEE buy now pay later
, receive the verification code, and finish the buy-now-pay-later payment flow.  
[](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明07.png)[![](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明07.png)](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明07.png)
[![](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明08.png)](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明08.png)
[![](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明09.png)](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明09.png) 4. Order paid:  
If the shopper's AFTEE buy-now-pay-later review passes, the admin shows Payment received and you can fulfill the order.  
If the shopper's AFTEE buy-now-pay-later review fails, follow the on-screen steps to try again, or ask the shopper to contact AFTEE buy now pay later
directly. [See the AFTEE official website.](https://aftee.tw/)  
[![AFTEE](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明10.png)](https://www.cyberbiz.io/support/wp-content/uploads/2021/10/AFTEE先享後付金流說明10.png) Other notes

1. Orders paid with AFTEE are canceled automatically if they are not shipped within 90 days.  
The system emails you 30, 15, 7, 3, and 1 day before auto-cancel to remind you to ship.  
*Preorder items (Product channel set to Preorder) are not auto-canceled.
2. AFTEE supports cardless installment plans. Shoppers who install the AFTEE app can choose [installments](https://netprotections.freshdesk.com/support/solutions/articles/70000197869-%E5%8F%AA%E6%9C%89app%E6%9C%83%E5%93%A1%E8%83%BD%E5%88%86%E6%9C%9F%E5%97%8E-) in the app.
